WAKARU v0.3.0 is available.

PDF, Word, and PowerPoint previews now include invert and sharpness/contrast controls. Live Illustrator follow-ups search the current page, source, or project with conversation context. 2026.09.08UPDATE

MLXBar v2.1.0 is available.

Added a local knowledge base (RAG). Import text into a collection and MLXBar splits it into chunks, embeds them through an external OpenAI-compatible embeddings endpoint (such as LM Studio), and stores the vectors. Add a rag field to a chat request and the most relevant passages are retrieved and prepended to the prompt automatically. It is off by default, and ordinary requests without rag behave exactly as before. Create collections, add documents and run a query test from the Settings screen (Japanese and English), mlxbarctl, or the management API.

↗
2026.09.08UPDATE

MLXBar v2.0.1 is available.

Fixed a bug in the multi-model residency pool. With "maximum resident models" set to 1, setting a same-model parallel instance count (replicas) of 2 or more still had the extra replicas rejected even with memory to spare, so concurrent requests to one model could not run in parallel. "Maximum resident models" now counts distinct model types only; the replica count is governed by a separate setting. The status output, mlxbarctl and the Settings screen also now show when replicas are short or when a saved "concurrent generation limit" is waiting for the next restart.
