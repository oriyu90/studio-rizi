Contrato de projeto

Um provedor. Nada mais refeito.

Uma diferença pequena é o critério de qualidade. Sem selecionar o MLXBar, o comportamento observável deve corresponder ao OpenCode v1.18.30.

01 / UPSTREAM

O comportamento existente permanece

Nenhuma mudança em interface, atalhos, agentes, prompts, ferramentas, MCP, permissões, sessões ou retentativas.

02 / LIMITS

Compactação automática nativa

Os limites efetivos de contexto e de entrada segura do MLXBar alimentam os metadados e a política existentes do OpenCode.

03 / FAILURE

Inicia sem o MLXBar

A descoberta é breve e limitada. Um servidor offline não derruba o OCode nem outro provedor.

Provider

Exatamente onde o OpenCode já lista modelos.

Não há assistente próprio nem outra tela. Inicie o MLXBar e use os seletores de provedor e modelo que você já conhece.

Descoberta dinâmica

Lê o inventário atual em GET /v1/models durante a inicialização.

Chat em streaming

Usa o caminho SDK compatível com OpenAI para respostas em streaming e chamadas de ferramentas.

Local ou LAN

Use o localhost padrão ou informe URL e token da LAN nas configurações normais do provedor.

Sem adivinhar capacidades

Visão, raciocínio e limites de tokens só são ativados por metadados explícitos, nunca pelo nome.

Começar

Inicie o MLXBar. Escolha um modelo.

A configuração local padrão não exige ajustes. Use as opções normais do OpenCode apenas para autenticação por token ou acesso via LAN.

  1. Inicie o MLXBarCarregue um modelo e ative a API compatível com OpenAI.
  2. Abra o OCode mlx-barNa inicialização, ele consulta brevemente /v1/models.
  3. Escolha o modelo MLXBarSelecione mlxbar/<model> no seletor existente.

        "apiKey": "YOUR_MLXBAR_TOKEN"
      }
    }
  }

Segurança pelo escopo

Limitado, isolado e explícito.

Pressão de memória do computador e estouro de contexto são condições diferentes, mesmo num provedor local.

Pressão ambígua permanece intacta

Só vira estouro de contexto quando o MLXBar declara explicitamente que é recuperável pelo contexto.

Sem limites inventados

Se o limite seguro de entrada estiver ausente, o adaptador não usa uma porcentagem arbitrária.

Limites de memória

A descoberta aceita no máximo 4 MiB e 10.000 modelos.

Sem registrar segredos

O adaptador não registra chaves, cabeçalhos de autorização, prompts nem resultados de ferramentas.
