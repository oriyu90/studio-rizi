Uma estação Debian,
no seu bolso.

mterm é um app de terminal de código aberto que executa o Debian Linux de verdade no seu Android. Sem root: chroot em espaço de utilizador via PRoot, terminal PTY genuíno e desenvolvimento com IA via Claude Code, tudo num só app.

Ver o código no GitHub Instalar o APK 
$ mterm --debian trixie
root@localhost:~# cat /etc/os-release
Debian GNU/Linux 13.7 (trixie)
root@localhost:~# claude
Welcome to Claude Code_

O seu Android vira uma máquina Linux.

Não um emulador de fachada: um espaço de utilizador Debian real a correr no aparelho. Instale pacotes com apt e use editores, compiladores e o Claude Code como sempre.

DEBIAN
Debian 13.7 trixie (arm64) incluído
Um sistema de ficheiros raiz arm64 oficial do Debian é extraído dentro do app. Um apt update liberta dezenas de milhares de pacotes, e Python, Node.js, git, vim e a sua toolchain diária funcionam como no desktop.
PROOT
chroot em espaço de utilizador, sem root
Um chroot via PRoot isola o ambiente Debian sem fazer root. A garantia e a integridade do sistema ficam intactas; tudo acontece dentro da sandbox do app.
PTY
Um terminal PTY genuíno
A shell liga-se através de um pseudo-terminal (PTY), por isso vim, tmux e prompts interativos comportam-se corretamente. Um emulador de terminal completo, com cores, Unicode e teclas tratados a sério.
CLAUDE
Desenvolvimento com IA via Claude Code
Corra o Claude Code dentro do ambiente Debian e programe em par com a IA inteiramente no aparelho. Um tablet em viagem vira uma máquina de desenvolvimento real.
HOME
Diretório home persistente
O diretório home do lado Debian persiste no armazenamento do app. Fechar o app não perde nada — continue exatamente de onde parou.
OSS
Código aberto sob licença MIT
O código está publicado no GitHub sob licença MIT, com instruções de compilação no README para qualquer pessoa reproduzir o mesmo APK.

Três edições para três formas de uso.

Três APKs assinados cobrem políticas de distribuição e SDKs-alvo diferentes. Todos estão no GitHub Releases.

  • FULL · TARGET SDK 28

    Completa (sideload)

    A compilação completa, com descarga do Debian incluída. Mira o SDK 28 para instalação fácil por sideload numa vasta gama de aparelhos — a escolha padrão.

    • Descarga e configuração do rootfs Debian incluídas
    • Funciona em muitos aparelhos com Android 10+
    • Instalação direta pelo GitHub Releases
  • MODERN · TARGET SDK 36 · EXPERIMENTAL

    Moderna (experimental)

    Uma compilação experimental alinhada com o comportamento mais recente do Android. Experimente primeiro, mas espere mudanças que podem quebrar.

    • Mira o SDK 36 com o comportamento mais recente
    • Pode conter mudanças experimentais
    • Para avaliação e feedback, não para uso diário
  • REMOTE · TARGET SDK 36 · NO DEBIAN DOWNLOAD

    Compatível remota

    Uma compilação amigável às políticas, sem descarga do Debian incluída. Traga o seu próprio rootfs ou use-a para alcançar anfitriões remotos.

    • Sem funcionalidade de descarga do Debian
    • Configurada para adequação às políticas
    • Para rootfs próprio e uso remoto

Recursos poderosos, defesa primeiro.

Correr Linux num telemóvel exige um desenho com a segurança primeiro. Sem atalhos arriscados — tudo distribuído de forma verificável.

  • Código nativo em conformidade com W^X — nunca cria memória simultaneamente gravável e executável, eliminando a base da injeção de código.
  • APKs assinados por sideload — cada APK é assinado pelo desenvolvedor, com hashes SHA-256 publicados para verificar antes de instalar.
  • Espelhos oficiais com verificação de checksum — o rootfs Debian vem de espelhos oficiais e é verificado por checksum antes da extração.
  • Ponte Android mínima — a passagem entre o app e o ambiente Debian é reduzida ao mínimo, sem permissões Android desnecessárias.
  • Redação de segredos nos registos — chaves de API e outros segredos são mascarados (redação) para os diagnósticos nunca os guardarem na íntegra.

Linux no seu aparelho em cinco minutos.

O mterm v1.1.0 está disponível como APKs assinados no GitHub Releases. É distribuído por sideload, fora das lojas — siga estes passos.

Passos do sideload

  1. 1Descarregue o APK da edição adequada no GitHub Releases e confira com o SHA-256 publicado.
  2. 2Permita “instalar apps desconhecidos” no Android e toque no APK para instalar.
  3. 3Abra o app, descarregue e extraia o rootfs Debian e arranque o seu primeiro ambiente Debian.
  4. 4Corra apt update && apt upgrade no terminal; para o Claude Code, escreva claude para começar.

Detalhes de compilação e assinatura no README

Requer Android 10 ou superior em arm64. Sem necessidade de root, mas o sideload exige permitir apps desconhecidos.
