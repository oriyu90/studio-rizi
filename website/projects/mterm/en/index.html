Your Android becomes a Linux machine.

Not a look-alike emulator: a real Debian userland running on the device. Install packages with apt and use your editors, compilers, and Claude Code as usual.

DEBIAN
Debian 13.7 trixie (arm64) built in
An official Debian arm64 root filesystem is unpacked inside the app. One apt update unlocks tens of thousands of packages, so Python, Node.js, git, vim and your everyday toolchain work as they do on desktop.
PROOT
Rootless user-space chroot
A PRoot-based chroot isolates the Debian environment without rooting. Your warranty and SafetyNet stay intact; everything stays inside the app sandbox.
PTY
A genuine PTY terminal
The shell is attached through a pseudo-terminal (PTY), so vim, tmux and interactive prompts behave correctly. A full-featured terminal emulator with proper colour, Unicode and key handling.
CLAUDE
AI development with Claude Code
Run Claude Code inside the Debian environment and pair-program with AI entirely on-device. A tablet on the road becomes a real development machine.
HOME
A persistent home directory
The Debian home directory persists in the app's storage. Closing the app loses nothing — pick up exactly where you left off.
OSS
MIT-licensed open source
The source is published on GitHub under the MIT licence, with build instructions in the README so anyone can reproduce the same APK.

Three editions for three ways of use.

Three signed APKs cover different distribution policies and target SDKs. All are available on GitHub Releases.

  • FULL · TARGET SDK 28

    Full (sideload)

    The full-featured build with Debian download included. Targets SDK 28 for easy sideloading across a wide range of devices — the default pick.

    • Debian rootfs download and setup included
    • Runs on a wide range of Android 10+ devices
    • Install directly from GitHub Releases
  • MODERN · TARGET SDK 36 · EXPERIMENTAL

    Modern (experimental)

    An experimental build tracking the latest Android behaviour. Try upcoming OS behaviour first, but expect breaking changes.

    • Targets SDK 36 with the latest behaviour
    • May contain experimental changes
    • For evaluation and feedback, not daily use
  • REMOTE · TARGET SDK 36 · NO DEBIAN DOWNLOAD

    Remote-compatible

    A policy-friendly build with no Debian download bundled. Bring your own rootfs or use it to reach remote hosts.

    • No Debian download feature
    • Configured for distribution-policy fit
    • For bring-your-own rootfs and remote use

Powerful features, defence first.

Running Linux on a phone demands a safety-first design. No risky shortcuts — everything is distributed in a verifiable form.

  • W^X-compliant native code — never creates memory that is both writable and executable, removing the basis for code injection.
  • Signed sideload APKs — every APK is developer-signed, with published SHA-256 hashes you can verify before installing.
  • Official mirrors with checksum verification — the Debian rootfs comes from official mirrors and is checksum-verified before extraction.
  • A minimal Android bridge — the handoff between the app and the Debian environment is kept to the bare minimum, with no unnecessary Android permissions.
  • Secret redaction in logs — API keys and other secrets are masked (redacted) so diagnostics never store them verbatim.

Linux on your device in five minutes.

mterm v1.3.0 is available as signed APKs on GitHub Releases. It is distributed via sideloading, outside app stores — follow these steps.

Sideloading steps

  1. 1Download the APK of the edition you need from GitHub Releases and check it against the published SHA-256.
  2. 2Allow “install unknown apps” on Android, then tap the APK to install it.
  3. 3Open the app, download and extract the Debian rootfs, and boot your first Debian environment.
  4. 4Run apt update && apt upgrade in the terminal; for Claude Code, type claude to begin.

Build and signing details in the README

Requires Android 10 or later on arm64. No rooting is needed, but sideloading requires allowing unknown apps.
