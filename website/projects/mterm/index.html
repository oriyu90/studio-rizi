mterm（エムターム）は、Android端末上でDebian Linuxをそのまま動かせるオープンソースのターミナルアプリです。root取得は不要で、PRootによるユーザー空間chrootと本物のPTYターミナル、Claude CodeによるAI開発を1つのアプリにまとめました。

GitHubでソースを見る APKをインストール 
$ mterm --debian trixie
root@localhost:~# cat /etc/os-release
Debian GNU/Linux 13.7 (trixie)
root@localhost:~# claude
Welcome to Claude Code_

v1.2.0では3エディション（完全版・モダン実験版・リモート対応版）の署名済みAPKをGitHub Releasesで配布しています。

Androidが、Linuxマシンになる。

エミュレーターの見せかけではなく、本物のDebianユーザー空間が端末の中で動きます。aptでパッケージを入れ、エディターやコンパイラー、Claude Codeまでそのまま使えます。

DEBIAN
Debian 13.7 trixie（arm64）を内蔵
Debian公式のarm64ルートファイルシステムをアプリ内に展開します。apt updateひとつで数万のパッケージが手に入り、Python・Node.js・git・vimなど日常の開発環境をそのまま再現できます。
PROOT
root不要のユーザー空間chroot
PRootによるchrootでroot化なしにDebian空間を分離します。端末の保証やセーフティネットを壊さず、アプリのサンドボックスの中で完結します。
PTY
本物のPTYターミナル
擬似端末（PTY）経由でシェルと接続するため、vim・tmux・対話プロンプトも正しく動作します。色・Unicode・キー入力を素直に扱えるフル機能のターミナルエミュレーターです。
CLAUDE
Claude CodeでAI開発
Debian空間にClaude Codeを導入し、端末の中だけでAIとペアプログラミングできます。外出先のタブレットが、そのまま開発マシンになります。
HOME
ホームは端末に永続保存
Debian側のホームディレクトリーはアプリの領域に永続化されます。アプリを閉じても作業内容は消えず、次回も続きから始められます。
OSS
MITライセンスのオープンソース
ソースコードはGitHubでMITライセンスとして公開しています。ビルド手順もREADMEに記載し、誰でも同じAPKを再現できます。

使い方に合わせて、3つのエディション。

配布ポリシーとターゲットSDKの違いで3つのAPKを用意しています。いずれも署名済みで、GitHub Releasesから入手できます。

  • FULL · TARGET SDK 28

    完全版（サイドロード用）

    Debianのダウンロード機能を含むフル機能版です。ターゲットSDK 28で幅広い端末へのサイドロード導入を想定した、まずはこれという一本です。

    • Debian rootfsの取得・展開に対応
    • Android 10以降の幅広い端末で動作
    • GitHub Releasesから直接インストール
  • MODERN · TARGET SDK 36 · EXPERIMENTAL

    モダン実験版

    最新のAndroid動作をターゲットにした実験版です。新しいOS挙動への追従を先行して試せますが、仕様変更の影響を受ける可能性があります。

    • ターゲットSDK 36の最新挙動に対応
    • 実験的な変更を含む場合あり
    • 常用前の検証・フィードバック向け
  • REMOTE · TARGET SDK 36 · NO DEBIAN DOWNLOAD

    リモート対応版

    ストア配布ポリシーに配慮し、Debianのダウンロード機能を含まない版です。お手持ちのrootfsを持ち込むか、リモートホストへの接続用途に向きます。

    • Debianダウンロード機能なし
    • 配布ポリシー適合を優先した構成
    • 持ち込みrootfs・リモート利用向け

強い機能ほど、防御を先に。

端末の中でLinuxを動かすからこそ、安全側の設計を積み重ねています。危険な近道は使わず、検証可能な形で配布します。

  • W^X準拠のネイティブコード — 書き込み可能かつ実行可能なメモリー領域を作らず、コード注入の土台をなくします。
  • 署名済みAPKのサイドロード — 配布APKは開発者署名済みで、SHA-256ハッシュを公開しています。ハッシュを確認してからインストールできます。
  • 公式ミラーとチェックサム検証 — Debian rootfsは公式ミラーから取得し、チェックサムで改ざんの有無を検証してから展開します。
  • 最小権限のAndroidブリッジ — アプリとDebian空間の受け渡しは必要最小限に絞り、不要なAndroid権限は求めません。
  • ログの秘匿情報マスキング — APIキーなどの秘密情報が診断ログにそのまま残らないよう、出力を編集（リダクション）して記録します。

5分で、端末がLinuxになる。

mterm v1.2.0はGitHub Releasesから署名済みAPKを入手できます。ストアを経由しないサイドロード配布のため、次の手順で導入します。

サイドロード導入手順

  1. 1GitHub Releasesから用途に合うエディションのAPKをダウンロードし、公開SHA-256と照合します。
  2. 2Androidの「提供元不明のアプリのインストール」を許可し、APKをタップしてインストールします。
  3. 3アプリを開き、Debian rootfsをダウンロード・展開して初回のDebian環境を起動します。
  4. 4ターミナルで apt update && apt upgrade を実行し、Claude Codeを使う場合は claude と入力して開始します。

READMEでビルド・署名の詳細を見る

対応OSはAndroid 10以降、CPUはarm64です。root化は不要ですが、提供元不明アプリの許可が必要なサイドロード配布です。
