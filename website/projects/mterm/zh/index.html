Debian 工作站。

mterm 是一款开源终端应用，可在 Android 手机上直接运行真正的 Debian Linux。无需 root：基于 PRoot 的用户空间 chroot、真正的 PTY 终端，以及 Claude Code 的 AI 开发，全部集成在一个应用中。

在 GitHub 查看源码 安装 APK 
$ mterm --debian trixie
root@localhost:~# cat /etc/os-release
Debian GNU/Linux 13.7 (trixie)
root@localhost:~# claude

让 Android 变成 Linux 电脑。

不是外观仿真的模拟器，而是在手机中真实运行的 Debian 用户空间。用 apt 安装软件包，编辑器、编译器、Claude Code 都可以照常使用。

DEBIAN
内置 Debian 13.7 trixie（arm64）
在应用内解压 Debian 官方 arm64 根文件系统。一条 apt update 即可获得数万个软件包，Python、Node.js、git、vim 等日常开发环境与桌面端完全一致。
PROOT
无需 root 的用户空间 chroot
通过 PRoot 实现 chroot 隔离，无需 root 权限。不影响保修与系统完整性，一切都在应用沙盒内完成。
PTY
真正的 PTY 终端
通过伪终端（PTY）连接 shell，vim、tmux、交互式提示都能正常工作。色彩、Unicode、按键输入都表现自然的全功能终端模拟器。
CLAUDE
用 Claude Code 进行 AI 开发
在 Debian 环境中运行 Claude Code，只用手机就能与 AI 结对编程。出门在外的平板，立刻变成开发机。
HOME
主目录持久保存在手机中
Debian 侧的主目录持久保存在应用存储中。关闭应用也不会丢失工作内容，下次可以接着继续。
OSS
MIT 协议开源
源代码以 MIT 协议在 GitHub 公开，README 中附有构建步骤，任何人都可以复现相同的 APK。

按用途选择，三个版本。

根据分发政策与目标 SDK 的差异，提供三个 APK，均为签名版本，可在 GitHub Releases 获取。

  • FULL · TARGET SDK 28

    完整版（侧载用）

    包含 Debian 下载功能的全功能版本。以目标 SDK 28 适配广泛机型的侧载安装，是首选推荐版本。

    • 支持 Debian 根文件系统获取与解压
    • 兼容广泛的 Android 10 及以上设备
    • 可从 GitHub Releases 直接安装
  • MODERN · TARGET SDK 36 · EXPERIMENTAL

    现代实验版

    面向最新 Android 行为的实验版本。可以抢先体验新系统行为，但可能受到规范变更的影响。

    • 以目标 SDK 36 为准的最新行为
    • 可能包含实验性变更
    • 适合验证与反馈，非日常使用
  • REMOTE · TARGET SDK 36 · NO DEBIAN DOWNLOAD

    远程兼容版

    考虑商店分发政策、不含 Debian 下载功能的版本。适合自带根文件系统，或连接远程主机的用途。

    • 不含 Debian 下载功能
    • 优先适配分发政策的构成
    • 适合自带根文件系统与远程使用

功能越强，防护越先行。

正因为在手机中运行 Linux，更要把安全设计放在前面。不走危险捷径，以可验证的形式分发。

  • 符合 W^X 的原生代码 — 不创建「可写又可执行」的内存区域，从根源上杜绝代码注入。
  • 签名 APK 侧载 — 所有分发 APK 均经开发者签名，并公开 SHA-256 哈希，核对后再安装。
  • 官方镜像与校验和验证 — Debian 根文件系统来自官方镜像，解压前先用校验和验证是否被篡改。
  • 最小权限的 Android 桥接 — 应用与 Debian 环境之间的数据传递控制在最小范围，不索取多余的 Android 权限。
  • 日志中的秘密信息脱敏 — 对 API 密钥等秘密信息做掩码（redaction）处理，诊断日志中不会原文保存。

五分钟，让手机变成 Linux。

mterm v1.3.0 可在 GitHub Releases 获取签名 APK。因不经过应用商店，采用侧载方式分发，请按以下步骤安装。

侧载安装步骤

  1. 1从 GitHub Releases 下载适合用途的版本 APK，并与公开的 SHA-256 核对。
  2. 2在 Android 中允许「安装未知应用」，点击 APK 进行安装。
  3. 3打开应用，下载并解压 Debian 根文件系统，启动第一个 Debian 环境。
  4. 4在终端执行 apt update && apt upgrade，使用 Claude Code 时输入 claude 即可开始。

在 README 查看构建与签名详情

需要 Android 10 及以上、arm64 处理器。无需 root，但侧载安装需要允许安装未知应用。
