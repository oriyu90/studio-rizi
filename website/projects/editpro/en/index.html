Edit Pro

A multimedia platform for music, video, image, and animation creation, powered by 24 plugins running in a safe sandbox.

View the latest release GitHub Discord community

The macOS DMG is ad-hoc signed and not notarized, so the first launch almost always requires approval under System Settings → Privacy & Security. Windows / Linux builds are planned via CI.

What it does

Multimedia engine

One core drives audio, images, and video with 5 IPC channels, shared memory, and clock sync.

24 plugins

Synths, mixers, and piano rolls plus brushes, layers, video timelines, codecs, and compatibility hosts.

Sandbox & watchdog

Plugins run isolated, and a watchdog detects crashes and restarts them automatically.

AI integration over MCP

A stdio MCP server (13 tools, 3 resources) lets apps like Claude Desktop operate Edit Pro.

Japanese/English UI

The desktop UI switches fully between Japanese and English, rendered with OS fonts to avoid tofu.

Canvas editor

Plugin drawings appear on a browser canvas, with mouse, keyboard, and pen input forwarded.

Workflow

Pick a profile→Launch→Edit & draw→Preview→Export
