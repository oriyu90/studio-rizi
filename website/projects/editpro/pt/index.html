Edit Pro

Uma plataforma multimídia para música, vídeo, imagem e animação, com 24 plug-ins em um sandbox seguro.

Ver a versão mais recente GitHub Comunidade no Discord

O DMG para macOS tem assinatura ad-hoc e não é autenticado (notarized); na primeira execução, quase sempre é preciso aprovar em Ajustes do Sistema → Privacidade e Segurança. Versões para Windows / Linux estão previstas via CI.

Recursos

Mecanismo multimídia

Um núcleo com 5 canais de IPC, memória compartilhada e relógio sincronizado move áudio, imagem e vídeo.

24 plug-ins

Sintetizadores, mixers e piano roll, além de pincéis, camadas, linhas do tempo de vídeo, codecs e hosts de compatibilidade.

Sandbox e watchdog

Os plug-ins rodam isolados, e um watchdog detecta falhas e reinicia automaticamente.

IA via MCP

Um servidor MCP stdio (13 ferramentas, 3 recursos) permite operar o Edit Pro a partir de apps como o Claude Desktop.

Interface JA/EN completa

A interface alterna totalmente entre japonês e inglês, com fontes do SO para evitar tofu.

Tela de edição em canvas

Os desenhos dos plug-ins aparecem em um canvas, com entrada de mouse, teclado e caneta.

Fluxo de trabalho

Escolher perfil→Iniciar→Editar e desenhar→Pré-visualizar→Exportar
