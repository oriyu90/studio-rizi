Edit Pro

音楽・動画・画像・アニメ制作を、24種のプラグインと安全なサンドボックス実行で支えるマルチメディアプラットフォームです。

最新リリースを見る GitHub Discordコミュニティ

macOS版DMGはad-hoc署名・未公証のため、初回起動時は「システム設定 → プライバシーとセキュリティ」からの許可がほぼ必ず必要になります。Windows / Linux版はCIビルドを提供予定です。

できること

マルチメディアエンジン

IPC 5ch・共有メモリ・時計同期で音声・画像・映像を一つのコアで駆動します。

24種のプラグイン

シンセ・ミキサー・ピアノロールからブラシ・レイヤー・動画タイムライン、コーデックや互換ホストまで同梱します。

サンドボックスと監視

プラグインを隔離実行し、ウォッチドッグがクラッシュを検知して自動再起動します。

MCPでAI連携

stdio MCPサーバ（13ツール・3リソース）によりClaude Desktop等から操作できます。

日英完全対応UI

デスクトップUIは日本語・英語の切替に対応し、OSフォント描画で文字化けを防ぎます。

Canvas編集画面

プラグインの描画をブラウザCanvasに表示し、マウス・キー・ペン入力を届けます。

基本ワークフロー

プロファイル選択→起動→編集・描画→プレビュー→書き出し
