Edit Pro

以 24 种插件与安全的沙箱执行，支撑音乐、视频、图像与动画制作的多媒体平台。

查看最新版本 GitHub Discord 社区

macOS 版 DMG 为 ad-hoc 签名且未经公证，首次启动通常需要在「系统设置 → 隐私与安全性」中批准。Windows / Linux 版计划通过 CI 提供。

功能

多媒体引擎

以 5 通道 IPC、共享内存与时钟同步，用同一个核心驱动音频、图像与视频。

24 种插件

合成器、混音器、钢琴卷帘，以及画笔、图层、视频时间线、编解码器与兼容宿主。

沙箱与看门狗

插件隔离运行，看门狗检测崩溃并自动重启。

通过 MCP 联动 AI

stdio MCP 服务器（13 个工具、3 类资源）可让 Claude Desktop 等应用操作 Edit Pro。

日英完整界面

桌面界面可在日语与英语之间完整切换，并使用系统字体渲染以避免缺字。

Canvas 编辑画面

插件绘制内容显示在浏览器画布上，并支持鼠标、键盘与数位笔输入。

基本流程

选择配置→启动→编辑与绘制→预览→导出
