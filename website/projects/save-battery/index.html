バッテリーを、賢く長持ちさせる。

Save battery は、macOS 27 / 26.4+ の Apple Silicon Mac で、Apple純正のネイティブ充電上限(80〜100%)をメニューバーから設定できる軽量ユーティリティです。特権を持たない単一プロセスで動作し、ドックには表示されません。

使い方

インストールから3ステップ

初回だけショートカットアプリに1つ作成すると、あとはメニューバーからいつでも充電上限を切り替えられます。

  1. ダウンロードして起動

    GitHub Releases から DMG をダウンロードし、アプリケーションフォルダへコピーして起動します。メニューバーにバッテリー残量が表示されます。

  2. ショートカットを1つ作成

    アプリ内のセットアップガイドに従い、ショートカットアプリで「バッテリー充電上限を設定」アクションを使ったショートカットを作成します（約1分）。このアクションはApple純正のため、アプリは特権を一切持ちません。

  3. 上限を選ぶだけ

    メニューバーの「充電上限」から 80 / 85 / 90 / 95 / 100% を選択。以後の充電管理（上限での停止、5%低下での再充電）はmacOS自身が安全に行います。

機能

軽量に、安全に、常駐する

充電のON/OFFは一切アプリが持たず、すべてOSのネイティブ機構に委譲する設計です。

ネイティブ充電上限
macOS 26.4以降に搭載されたApple純正の充電上限(80〜100%)を、公式のショートカットアクション経由で設定します。private APIや特権daemonは使いません。
メニューバー常駐・ドック非表示
バッテリー残量と充電状態をメニューバーに常時表示。アプリはドックに現れず、邪魔になりません。
軽量設計
常駐は単一プロセスのみ。電源状態の監視はIOKitのイベント駆動で、高頻度のポーリングを行いません。
クラッシュ安全性
force unwrap を排除し、外部処理はすべてタイムアウト付き。何かが失敗してもアプリは壊れず、監視のみのRead-onlyモードへ自動降格します。
充電の安全フェイル
アプリが終了・クラッシュしても、上限設定はOS側に保持されるため、Macは常にApple標準の充電管理下にあります。
バッテリー健全性
サイクル数と最大容量(設計比)を診断ウィンドウで表示。ワンクリックでクリップボードにコピーでき、不具合報告にも使えます。
今すぐ100%まで充電
出発前に満充電したいときは、メニューからワンクリック。上限を一時的に100%へ変更します。
ログイン時起動
SMAppServiceを使い、ログイン時に自動で常駐します（メニューからワンクリックで切替）。
日本語 / English
UIは日本語と英語に完全対応しています（システム言語で自動切替）。

動作環境とビルド

macOS 26.4 以降（macOS 27 正式対応）

動作環境

  • ◆ macOS 26.4 以降（macOS 27 / Golden Gate 対応）・Apple Silicon Mac（内蔵バッテリー搭載機）
  • ◆ 充電上限の制御には macOS 26.4+ の「バッテリー充電上限を設定」ショートカットアクションが必要
  • ◆ ad-hoc 署名（未公証）。初回起動は「システム設定 › プライバシーとセキュリティ」から許可
