使用方法

安装后只需三步

首次使用时在"快捷指令"中创建一条快捷指令，之后即可随时从菜单栏切换充电上限。

  1. 下载并启动

    从 GitHub Releases 下载 DMG，将应用拷贝到"应用程序"文件夹并启动。菜单栏会显示电池电量。

  2. 创建一条快捷指令

    按照应用内的设置指南，使用系统内置的"设置电池充电上限"操作创建快捷指令（约1分钟）。该操作由 Apple 官方提供，因此应用本身不拥有任何特权。

  3. 选择上限

    在菜单栏的"充电上限"中选择 80 / 85 / 90 / 95 / 100%。之后的充电管理（到达上限停止、下降 5% 后恢复充电）由 macOS 自身安全完成。

功能

轻量、安全、常驻

应用自身不执行任何充电开关控制，所有控制均委托给 macOS 原生机制。

原生充电上限
通过官方快捷指令操作设置 macOS 26.4 内置的 Apple 原生充电上限（80–100%）。不使用私有 API，也没有特权守护进程。
菜单栏常驻·程序坞隐藏
电池电量与充电状态常驻菜单栏，应用不会出现在程序坞中。
轻量设计
仅一个常驻进程。电源状态通过 IOKit 事件通知驱动，不做高频轮询。
崩溃安全
杜绝强制解包，所有外部调用均有超时限制。即使发生故障，应用也不会崩溃，而是自动降级为只读监控模式。
充电安全兜底
应用退出或崩溃后，上限设置仍由系统保留，Mac 始终处于 Apple 标准充电管理之下。
电池健康
诊断窗口显示循环次数与最大容量（相对设计容量），一键复制即可用于问题报告。
立即充至100%
出发前需要充满电？在菜单中一键将上限临时设置为 100%。
登录时启动
通过 SMAppService 注册，登录后自动常驻（可在菜单中一键切换）。
日本語 / English
界面完整支持日语和英语（跟随系统语言自动切换）。

系统要求与构建

macOS 26.4 或更高版本（正式支持 macOS 27）

系统要求

  • ◆ macOS 26.4+（支持 macOS 27 / Golden Gate）· 搭载内置电池的 Apple Silicon Mac
  • ◆ 充电上限控制依赖 macOS 26.4+ 内置的"设置电池充电上限"快捷指令操作
  • ◆ Ad-hoc 签名（未经公证）。首次启动需在"系统设置 › 隐私与安全性"中允许
