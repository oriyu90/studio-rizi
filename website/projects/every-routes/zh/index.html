ANDROID + PYTHON 服务器 · MIT 开源

把度过一天的方式，变成档案。

注册一次「工作日」「休息日」作息，即可按星期与节假日规则每天自动套用。Google Tasks 与 AI 智能体的任务也会显示在同一条时间线上。换机与多设备可经由共享服务器继承数据。

WHAT IT DOES

注册的不是日程，而是过法。

日历记录的是「每天的日程」，Every routes 复用的是「一天本身的样子」。

01

作息档案

把「工作日」「休息日」等一天的流程注册为时间段集合，并用星期标签与节假日策略（排除、包含、仅节假日）指定重复条件。

02

今日视图

把当天适用的时间段与当天任务合并为一条时间线，突出显示正在进行与接下来的安排，也可翻看前后日期确认未来计划。

03

任务汇总

Google Tasks 获取、手动输入、智能体创建的任务带有来源图标统一显示，完成操作会同步回共享服务器。

04

离线优先

创建、编辑与查看全部在设备端完成。即使不配置服务器也可单独使用，仅在联网时同步。

05

应用内 WireGuard VPN

连接服务器时由应用自行建立 WireGuard 隧道（默认关闭）。支持导入 .conf、手动输入与删除；仅本应用走 VPN，其他应用与共享网络不受影响。

今日视图示例 — 9月11日（星期五・工作日）

  1. 07:00起床・准备工作日
  2. 09:00通勤工作日
  3. 10:00去银行智能体
  4. 12:00午餐工作日
  5. 15:00看牙医Google Tasks

SHARED HUB

共享服务器是多个应用的中转站。

面向家庭局域网与 VPN 的轻量服务器（FastAPI＋单个 SQLite 文件）。它不只属于 Android：外部应用与 AI 智能体可用同一 API 与同一令牌读写。同步以作息地址为准，保留最后修改时间较新的一方。

一条命令即可启动

准备好配置文件后直接运行。

pip install every-routes-server
every-routes-server --config ./every-routes.yaml

支持智能体协作

智能体写入的「明天要做的事」，会在次日早晨同步到手机。

POST /api/v1/tasks
{"source":"agent","title":"去银行",
 "at":"2026-09-11T10:00:00+09:00"}

GET STARTED

三步即可开始。

  1. 1

    安装应用

    从 GitHub Releases 获取签名版 APK（android-v1.0.1）。

  2. 2

    创建工作日档案

    选择周一到周五并排除节假日，添加时间段后，当天起就会显示在今日视图中。

  3. 3

    连接服务器（可选）

    在设置中输入服务器地址与令牌。「上传到服务器」可共享档案，「导入」可迁移到另一台设备。
