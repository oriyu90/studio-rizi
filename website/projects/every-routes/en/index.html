WHAT IT DOES

Register how you live, not just appointments.

Calendars store per-date events. Every routes reuses the shape of the day itself.

01

Routine profiles

Save the flow of a day — “weekday”, “holiday” — as a set of time blocks, with weekday chips and a holiday policy (exclude, include, holidays only).

02

Today view

Matching blocks and the day’s tasks merge into one timeline, highlighting what is happening now and next. Flip dates to preview the days ahead.

03

Unified tasks

Google Tasks imports, manual entries, and agent-created tasks appear with source icons. Completing a task syncs back to the shared server.

04

Offline first

Creating, editing, and viewing all work on-device. The app stands alone without a server and syncs only when connected.

05

In-app WireGuard VPN

The app opens its own WireGuard tunnel when reaching the server (off by default). Import a .conf, enter it manually, or delete it; only this app goes through the VPN while everything else stays on the regular connection.

SHARED HUB

The server is a handoff point for many apps.

A lightweight server (FastAPI plus a single SQLite file) for home LAN or VPN use. It is not Android-only: external apps and AI agents read and write through the same API with the same bearer token. Sync matches by routine address and keeps the newer last-modified timestamp.

One command to run

Write a config file and start it.

pip install every-routes-server
every-routes-server --config ./every-routes.yaml

Agent friendly

An agent’s “do this tomorrow” reaches the phone at the next morning sync.

POST /api/v1/tasks
{"source":"agent","title":"Go to the bank",
 "at":"2026-09-11T10:00:00+09:00"}

GET STARTED

Start in three steps.

  1. Install the app

    Get the signed APK (android-v1.0.0) from GitHub Releases.

  2. Create a weekday profile

    Pick Monday to Friday, exclude holidays, add time blocks — they show up in the Today view from that day.

  3. Connect a server (optional)

    Enter the base URL and token in Settings. “Upload to server” shares a profile; “Import” carries it to another device.
