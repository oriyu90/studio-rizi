WHAT IT DOES

予定ではなく、過ごし方を登録する。

カレンダーが「日付ごとの予定」を置くのに対し、Every routesは「1日の流れそのもの」を繰り返し使います。

01

ルーティンプロファイル

「平日」「休日」などの1日の流れを、時間帯ブロックの集まりとして登録。曜日チップと祝日ポリシー（除外・含む・祝日のみ）で繰り返し条件を指定します。

02

今日ビュー

その日に適用されるブロックと、その日のタスクを1本の時系列に統合。進行中・次の予定を強調し、日付を前後にめくって先の予定も確認できます。

03

タスク統合

Google Tasksの取得、手動入力、AIエージェント由来を発生源アイコン付きで統合。完了操作は共有サーバーへ反映されます。

04

オフライン優先

作成・編集・表示はすべて端末内で完結。サーバー未設定でも単体で使え、接続時のみ同期します。

今日ビューの例 — 9月11日（金・平日）

  1. 07:00起床・準備平日
  2. 09:00通勤平日
  3. 10:00銀行に行くエージェント
  4. 12:00昼食平日
  5. 15:00歯医者Google Tasks

SHARED HUB

共有サーバーは、複数アプリの受け渡し点。

家庭内LAN・VPNでの運用を想定した軽量サーバー（FastAPI＋SQLite単一ファイル）。Android専用ではなく、同じAPI・同じBearerトークンで外部アプリやAIエージェントも読み書きできます。同期はルーティンアドレスで突き合わせ、更新は最終変更日時の新しい方を採用します。

起動は1コマンド

設定ファイルを用意して実行するだけです。

pip install every-routes-server
every-routes-server --config ./every-routes.yaml

エージェント連携

「明日これをやる」をサーバーへ書き込むと、翌朝の同期で端末に届きます。

POST /api/v1/tasks
{"source":"agent","title":"銀行に行く",
 "at":"2026-09-11T10:00:00+09:00"}

GET STARTED

3ステップで、はじめる。

  1. アプリを入れる

    GitHub Releasesから署名済みAPK（android-v0.1.0）を取得します。

  2. 平日プロファイルを作る

    月〜金・祝日除外で時間帯ブロックを登録すれば、その日から今日ビューに並びます。

  3. サーバーにつなぐ（任意）

    設定画面でベースURLとトークンを入力。「サーバーへアップロード」で共有、「インポート」で別端末へ引き継ぎます。
