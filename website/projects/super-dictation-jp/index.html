super-dictation-jp / スーパーディクテーション音声を聞いて、
2つのクイズに答える。

毎日5問、耳で聞き取る練習ができる小・中学生向けドリルです。1問につき20秒ほどの音声を1回聞いて、下に出る2つのクイズに答えます。答え合わせでは正誤と音声の文が表示され、そのあとは何度でも音声を聞き直せるので、聞き取れなかったところを確かめられます。

アプリを始める GitHub で見る

できること

「聞く → 答える → 確かめる」を、そのまま1ページに。

11問=2クイズ、1セット5問

20秒ほどの音声に2つのクイズが付きます。1セットは5問で10点満点。答え合わせでは◎◯△✕で採点し、音声の文も表示します。

25レベル・400パターン

計算なしの「簡単」から、かけ算・わり算や追加情報の「難関」、日またぎの「最難関」まで5レベル。全部で400パターン・800問を用意しています。

3音声は1回、答え合わせ後は自由

本番の音声は1回だけ(途中の一時停止→再開はOK)。答え合わせのあとは「音声を聞こう」ボタンで何度でも聞き直せます。

4書きやすい「ます」入力

文字の答えは1ます、数字の答えはけたぶんのます。ますを押すと選択肢が出るので、小さい子でも迷わず入力できます。

5記録は端末内だけ

きょうの採点・昨日までの平均・7日ぶんの履歴をホームに表示。データは端末内(IndexedDB)にのみ保存し、広告・解析・アカウント登録はありません。

6音声つきデモ付き

初めてでも大丈夫。ホームの「音声つきデモ(声あり 5問)」なら、記録に残さず5問ぶんをその場で試せます。

進め方

1問は「聞く → 答える → 答え合わせ」の3ステップ。1セット5問で終わったら成績が出ます。

1

音声を聞く

「音声を聞こう」を押して、20秒ほどの文章を聞きます。問題は音声を最後まで聞くまでぼかされています。

2

ますに答える

2つのクイズに答えます。文字は1ますに、数字はけたごとのますに入力。押すと選択肢のポップが出ます。

3

答え合わせ

正誤(◎◯△✕)と音声の文が表示されます。このあとは音声を聞き直せるので、聞き逃したところを確認しましょう。

レベル

5レベルで、聞き取りと考え方の難しさを段階的に上げます。

レベル問題数内容
簡単100問(20パターン×5)計算なし。3文を聞いて、すぐこたえる。
標準100問指示語で間接的に聞く。足し算・引き算も少し。
応用100問計算や人の関係が、もう一段むずかしく。
難関50問かけ算・わり算が登場。追加の情報にも注意。
最難関50問電車の遅れ・日またぎなど、量も概念も多い。

仕様

公開URLhttps://sd-jp.pages.dev/
料金無料(広告・解析・アカウント登録なし)
問題数400パターン × 2クイズ = 800問(1セット5問・10点満点)
音声全400問に生成音声つき。1問1回再生(途中で一時停止→再開は可)。答え合わせ後は聞き直し自由
入力ます式(文字=1ます / 数字=けたます+まとまり表示)、4択、書き込み
記録端末内のみ(IndexedDB)。きょうの採点・昨日までの平均・7日履歴
ソースコードgithub.com/oriyu90/super-dictation-jp(MIT License)

まずは5問、試してみませんか。

インストール不要・登録不要。音声つきデモ(声あり 5問)なら、記録に残さずその場で体験できます。
