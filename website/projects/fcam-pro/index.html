撮る手を、
プロの手に。

Fcam pro（エフカムプロ）は、マニュアル露出、物理レンズの実切り替え、撮影プロファイル、バックグラウンド録画を備えたAndroid向けのオープンソースなカメラアプリです。登録もアカウントも不要で、OSの標準カメラアプリにも設定できます。

署名済みAPKを入手 GitHubでソースを見る

ISO・シャッター速度・フォーカス・ホワイトバランスの各スライダーは、選択中の物理カメラが対応する範囲に自動でクランプされます。

  • 対応OSAndroid 7.0 以降
  • UI言語日本語 / English
  • ライセンスMIT / 無料

必要な操作を、ファインダーの上で。

写真と動画、それぞれのモードで責務を分け、プロ向けの操作をプレビューを覆わずに配置しています。

LENSES
物理レンズを実切り替え
超広角・広角・望遠・マクロ・前面。レンズ向きのフラグではなく実際の cameraId をバインドします。対応しない端末では当該向きの既定カメラへ安全にフォールバックします。
FOCUS
タップAFとピンチズーム
プレビュー上のタップで測光・フォーカス、ピンチでズーム。AE/AFロック中は自動で無効になります。
PROFILES
撮影プロファイル
マニュアル設定を保存・改名・削除して呼び出し。Roomデータベースに保存し、アップデート時もクラッシュしない破壊的マイグレーションで管理します。
TIME-LAPSE
タイムラプス
間隔は1〜10秒で設定可能。連続してエラーが起きた場合は自動停止し、画面を離れると確実に止まります。
BACKGROUND
バックグラウンド録画
フォアグラウンドサービスで画面オフ中も録画を継続。通知の停止ボタンで終了でき、アプリ側のカメラとは排他制御します。
QR
QRコード検出
写真モードで自動検出。URLはそのまま開き、それ以外はクリップボードにコピーします。
SYSTEM
OSの標準カメラに設定可能
IMAGE_CAPTURE / VIDEO_CAPTURE / STILL_IMAGE_CAMERA を処理し、呼び出し元へ結果を返します。

端末が対応する範囲だけを、確実に。

マニュアルモードでは、選択中のカメラの CameraCharacteristics から ISO 感度・露光時間・最短フォーカス距離・利用可能なAWBモードを読み取り、スライダーの範囲と設定値をその端末の実力に合わせて制限します。MANUAL_SENSOR 非対応のカメラでは、マニュアルボタン自体を無効化して黒画面や例外を防ぎます。

  • ISO 感度
  • シャッター速度
  • フォーカス距離
  • ホワイトバランス
  • AE / AF ロック
  • マイク Mono / Stereo

日本語と英語、どちらも完全対応。

UIの全文言・読み上げ用ラベル・通知文言を日本語と英語で用意しています。アプリ内の設定から「システム / 日本語 / English」を切り替えでき、初期値は端末の言語（未対応の言語は英語）に従います。

  • 日本語
  • English

署名済みAPKをすぐ試せます。

Fcam pro v1.0.0 は GitHub Releases から署名済みAPKを入手できます。対応OSは Android 7.0（API 24）以降です。

入手・ビルド

  1. 1GitHub Releases から Fcam-pro-v1.0.0.apk をダウンロードし、SHA256SUMS.txt と照合してインストールします。
  2. 2ソースから試す場合は GitHubリポジトリ をクローンします。
  3. 3JDK 21 と Android SDK 36 / Build-Tools 36.0.0 を用意します。
  4. 4ターミナルで ./gradlew assembleDebug を実行します。
