S3DV viewer

3D流媒体播放/验证查看器

macOS Swift v1.2.0 日英UI

S3DV viewer 是用于在 macOS 上播放和验证录制的 .s3dv 时间序列3D流的原生查看器。WKWebView + three.js (r180) 批量渲染，实现每个竞技场一个绘制调用。

帧完整呈现 (Frame-complete presentation)

即使在高负载下，也能确保每一帧完整渲染后再进入下一帧。接收的数据包不会立即应用，而是先缓冲到接收箱，在渲染tick内按顺序完整应用后，才作为一帧呈现。如果预算用尽，中间帧会被丢弃，只呈现后续的完整状态，因此永远不会显示撕裂的帧（例如只应用了一半的快照）。

  • 呈现的帧始终是数据包边界处的完整场景状态 — 应用中的状态不会显示
  • 高负载时花费加载时间并丢弃帧 — 每个渲染tick的应用预算（默认6 ms）；溢出部分折叠到下一个完整状态
  • 纹理在解码完成后组合 — 不会出现白色的未完成帧
  • 隐藏窗口在到达时立即应用 — 当 rAF 被限制为 ~1 Hz 时禁用节奏控制，防止数据包积压

主要特性

  • 数据包完整性: 引擎发送计数 == 页面应用计数 (page packets == framesSent)
  • 批量渲染: 一个竞技场 = 一个绘制调用；8,236个块减少到约10个绘制调用
  • 内存预算管理: 超过常驻几何体预算时，驱逐最旧/最外侧块
  • 崩溃安全: 检测 WebContent 进程终止并自动恢复（最多2次）
  • CLI控制: 通过 UNIX 套接字使用 s3dvctl 进行全操作（open/pause/step/seek/speed/presentation/applybudgetms/bench/screenshot/wait/quit）
  • 设置: 演示模式（frameComplete/immediate）和应用预算（1–50 ms）可实时切换
