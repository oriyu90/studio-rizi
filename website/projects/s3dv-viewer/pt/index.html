S3DV viewer

Visualizador/verificador de stream 3D

macOS Swift v1.2.0 UI JA/EN

S3DV viewer é um visualizador nativo para macOS para reproduzir e verificar streams .s3dv gravados (séries temporais 3D). Renderização em lote com WKWebView + three.js (r180), entregando um draw call por arena.

Apresentação completa de quadro (Frame-complete presentation)

Projetado para que cada quadro seja renderizado completamente antes de passar para o próximo, mesmo sob carga elevada. Pacotes recebidos são bufferizados em uma fila de entrada e aplicados em ordem dentro do tick de renderização antes de um único quadro ser apresentado. Se o orçamento for esgotado, quadros intermediários são descartados e apenas o estado completo posterior é apresentado — portanto um quadro rasgado (ex. snapshot metade aplicado) nunca é mostrado.

  • Quadros apresentados são sempre estados completos da cena em limites de pacote — estados parcialmente aplicados nunca são mostrados
  • Sob carga, tempo de carregamento é gasto e quadros são descartados — orçamento de aplicação por tick (padrão 6 ms); excedente é dobrado no próximo estado completo
  • Texturas são incorporadas após a conclusão da decodificação — nenhum quadro branco não renderizado
  • Janelas ocultas aplicam na chegada — o ritmo é desabilitado quando o rAF é limitado a ~1 Hz, evitando backlog de pacotes

Principais recursos

  • Integridade de pacotes: contagem enviada pelo motor == contagem aplicada pela página (page packets == framesSent)
  • Renderização em lote: uma arena = um draw call; 8.236 blocos reduzidos para ~10 draw calls
  • Governador de orçamento de memória: blocos mais antigos/externos são evacuados quando o orçamento de geometria residente é excedido
  • Segurança contra falhas: terminação do processo WebContent detectada e auto-recuperada (máx. 2 vezes)
  • Controle por CLI: operação completa via s3dvctl sobre soquete UNIX (open/pause/step/seek/speed/presentation/applybudgetms/bench/screenshot/wait/quit)
  • Configurações: modo de apresentação (frameComplete/immediate) e orçamento de aplicação (1–50 ms) comutáveis ao vivo
