S3DV viewer

3D stream playback / verification viewer

macOS Swift v1.2.0 JA/EN UI

S3DV viewer is a native macOS viewer for playing back and verifying recorded .s3dv time-series 3D streams. WKWebView + three.js (r180) batched rendering delivers one draw call per arena.

Frame-complete presentation

Designed so that each frame is rendered completely before moving to the next, even under heavy load. Received packets are buffered in an inbox and applied in order within the render tick before a single frame is presented. If the budget is exhausted, intermediate frames are dropped and only the later complete state is presented — so a torn frame (e.g. half-applied snapshot) is never shown.

  • Presented frames are always complete scene states at packet boundaries — partially applied states are never shown
  • Under load, load time is taken and frames are dropped — per-tick apply budget (default 6 ms); overflow is folded into the next complete state
  • Textures are incorporated after decode completes — no white unrendered frames
  • Hidden windows apply on arrival — pacing is disabled when rAF is throttled to ~1 Hz, preventing packet backlog

Key features

  • Packet integrity: engine sent count == page applied count (page packets == framesSent)
  • Batched rendering: one arena = one draw call; 8,236 chunks reduced to ~10 draw calls
  • Memory budget governor: oldest/outer chunks evicted when resident geometry budget is exceeded
  • Crash safety: WebContent process termination detected and auto-recovered (max 2 times)
  • CLI control: full operation via s3dvctl over UNIX socket (open/pause/step/seek/speed/presentation/applybudgetms/bench/screenshot/wait/quit)
  • Settings: presentation mode (frameComplete/immediate) and apply budget (1–50 ms) switchable live
