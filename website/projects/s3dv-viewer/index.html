S3DV viewer

時系列3Dストリームの再生・検証用ビューア

macOS Swift v1.2.0 日英UI

S3DV viewerは、記録された .s3dv 時系列3Dストリームを再生・検証する macOS ネイティブビューアです。WKWebView + three.js (r180) によるバッチ描画で、1ドローコール/アリーナのレンダリングを実現しています。

フレーム完全提示 (Frame-complete presentation)

負荷が高い場合でも、1つ1つのフレームを確実に描画してから次のフレームに移る設計です。受信パケットは即座に適用せず受信箱にバッファし、描画tick内で順序どおりに完全適用してから1フレームとして提示します。途中で予算を使い切った場合は中間フレームを落とし、後続の完全な状態だけを提示するため、途切れた帧（スナップショット半分適用など）が表示されることはありません。

  • 提示フレームは常にパケット境界の完全なシーン状態 — 適用途中の状態は表示されません
  • 負荷時はロード時間をとり、フレームを落とす — 1描画tickの適用予算(既定6 ms)内で適用し、超過分は次の完全状態へ折り畳み
  • テクスチャはデコード完了後に組み込み — 白飛びの未完成フレームを出さない
  • 非表示ウィンドウでは到着時に即適用 — rAFが~1 Hzに抑制される隠蔽時はペース制御を無効化し、パケットの滞留を防ぐ

主な特徴

  • パケット完全性: エンジン送信数とページ適用数が一致 (page packets == framesSent)
  • バッチ描画: 1アリーナ = 1ドローコール。8,236チャンク → 10ドローコール程度に削減
  • メモリ予算ガバナ: 常駐ジオメトリ予算超過時は古い/外側チャンクを退避
  • クラッシュ安全性: WebContentプロセス終了を検知して自動復帰(最大2回)
  • CLI制御: UNIXソケット経由で s3dvctl から全操作 (open/pause/step/seek/speed/presentation/applybudgetms/bench/screenshot/wait/quit)
  • 設定: 提示モード(frameComplete/immediate)・適用予算(1–50 ms)をライブ切替
