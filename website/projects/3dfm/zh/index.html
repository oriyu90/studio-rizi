在这台 Mac 上，把图片变成3D 模型。

3DFM 是常驻菜单栏的 macOS 应用，可将图片生成 3D GLB 模型。支持普通模式（TRELLIS.2）与人物模式（Hunyuan3D＋MV-Adapter 合成）。沉重的模型文件位置可在设置中更改。

Setup

3 步开始使用

一键安装会自动引入运行时与 AI 模型。保存位置可在之后于设置中更改。

  1. 启动应用

    从 DMG 打开 3DFM.app（首次请右键→打开）。应用常驻菜单栏，不显示在 Dock 中。

  2. 运行安装

    选择输出文件夹与模型档（普通/人物）。首次可能需要几十分钟。

  3. 提交图片

    在新建生成中选择图片并加入队列。可查看进度、日志与 GLB 成果物，与 CLI 3dfm submit 相同。

Features

主要功能

生成队列、取消、GUI=CLI 一致、完全本地。v0.3.0 新增存储位置设置。

普通模式
单张图片经 TRELLIS.2 生成形状＋PBR 贴图并输出 GLB（512 预览 / 512→1024 标准 / 512→1536 最高）。
人物模式
6 视角输入，或单张正面照→MV-Adapter 合成其余 5 视角。TRELLIS.2 形状＋Hunyuan MLX 绘制的混合管线。
存储位置设置 (v0.3.0)
在设置＞存储中更改数据文件夹与模型文件夹。模型由服务器移动（需清空队列），数据需停止→移动→重启。支持外置 SSD（3dfm storage status）。
队列与安全
FIFO 队列、协作取消、SQLite(WAL) 保存、OOM/停滞看门狗。崩溃后历史记录仍保留。
离线运行
模型下载后可完全离线生成（无遥测）。许可信息汇总于设置＞模型。

Requirements

运行环境与分发

运行环境

  • Apple Silicon（M1 及更新）/ macOS 14 及更新（推荐 26+）
  • 内存最低 16GB、推荐 24GB+、人物模式 40GB+ 更流畅
  • 磁盘：普通约 20GB / 人物完整约 60GB
  • ad-hoc 签名未公证，首次启动需要手动允许

CLI 示例

3dfm status
3dfm submit --mode normal -i img.png
3dfm storage status
3dfm storage move-models /Volumes/SSD/3DFM-models
3dfm models ensure --tier human
