Image to 3D model, on this Mac.

3DFM lives in the menu bar and turns images into 3D GLB models. Normal mode (TRELLIS.2) plus human mode (Hunyuan3D with MV-Adapter synthesis). Heavy model files can be moved in Settings.

Setup

Start in 3 steps

One-button setup installs runtimes and AI models automatically. Locations can be changed later in Settings.

  1. Launch the app

    Open 3DFM.app from the DMG (Right-click → Open first time). It lives in the menu bar, not the Dock.

  2. Run setup

    Pick an output folder and a model tier (normal/human). The first run may take tens of minutes.

  3. Submit images

    Choose images in New Generation. Track progress, logs and GLB artifacts. Same as CLI 3dfm submit.

Features

Highlights

Job queue, cancel, GUI=CLI parity, fully local. v0.3.1 adds configurable storage locations.

Normal mode
Single image to shape + PBR texture GLB via TRELLIS.2 (512 preview / 512→1024 default / 512→1536 max).
Human mode
6 views, or 1 front photo → 5 synthesized views via MV-Adapter. Hybrid TRELLIS.2 shape + Hunyuan MLX paint.
32GB+ guarantee (v0.3.1)
Verified setup + standard generation on all 32GB+ Apple Silicon Macs. 512 / 512->1024 + 2048 + MV512 work on all RAM sizes. 512->1536 / 4096 need 32GB+; combo + MV768 need 48GB+ (bilingual 422).
Storage locations (v0.3.0/v0.3.1)
Change data and models folders in Settings > Storage. Server moves models (idle queue required); data moves offline with restart. External SSD supported (3dfm storage status).
Queue & safety
FIFO queue, cooperative cancel, SQLite (WAL) history, OOM/stall watchdogs. History survives crashes.
Offline
Fully offline generation after models are fetched (no telemetry). Licenses live in Settings > Models.

Requirements

Requirements & distribution

Requirements

  • Apple Silicon (M1+) / macOS 14+ (26+ recommended)
  • 16 GB minimum, 24 GB+ recommended, 32GB+ verified (v0.3.1), 40 GB+ for human
  • Disk: ~20 GB normal / ~60 GB human-full
  • Ad-hoc-signed and unnotarized; approval needed on first launch

CLI example

3dfm status
3dfm submit --mode normal -i img.png
3dfm storage status
3dfm storage move-models /Volumes/SSD/3DFM-models
3dfm models ensure --tier human
