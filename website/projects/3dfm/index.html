画像から、3DモデルをこのMacで。

3DFMは、メニューバーに常駐して画像から3Dモデル(GLB)を生成するmacOSアプリです。普通モード (TRELLIS.2) と人物モード (Hunyuan3D＋MV-Adapter合成) に対応。重いモデルファイルの置き場所は設定で変えられます。

Setup

3ステップで開始

ワンボタンのセットアップがランタイムとAIモデルを自動導入します。保存場所は後から設定で変更できます。

  1. アプリを起動

    DMGから3DFM.appを開きます（初回は右クリック→開く）。メニューバーに常駐し、Dockには表示されません。

  2. セットアップ実行

    出力フォルダとモデルtier（普通/人物込み）を選びます。初回は数十分かかることがあります。

  3. 画像を投入

    新規生成から画像を選びキューへ。進捗・ログ・GLB成果物を確認できます。CLI 3dfm submit と同一操作です。

Features

主な機能

生成キュー・キャンセル・GUI=CLIパリティ・ローカル完結。v0.3.1で保存場所の設定に対応しました。

普通モード
1枚の画像からTRELLIS.2で形状＋PBRテクスチャを生成しGLB出力（512プレビュー / 512→1024標準 / 512→1536最高）。
人物モード
6視点入力または正面1枚→MV-Adapterで5視点合成。TRELLIS.2形状＋Hunyuan MLXペイントのハイブリッドでPBR化。
32GB+保証 (v0.3.1)
32GB以上の全Apple Silicon Macでセットアップ完走・通常生成を検証。512 / 512→1024 + 2048 + MV512は全RAMで動作。512→1536 / 4096は32GB+必須、1536+4096併用とMV768は48GB+必須（不足時は日英422で案内）。
保存場所の設定 (v0.3.0/v0.3.1)
設定＞ストレージでデータフォルダとモデルフォルダを変更可。モデルはサーバーが移動（キュー空き必須）、データは停止→移動→再起動。外付けSSD対応（3dfm storage status）。
キューと安全性
FIFOキュー・協調キャンセル・SQLite(WAL)保持・OOM/停滞ウォッチドッグ。クラッシュしても履歴は残ります。
オフライン
モデル取得後は完全オフライン生成可（テレメトリなし）。ライセンス表示は設定＞モデルに集約。

Requirements

動作環境・配布

動作環境

  • Apple Silicon (M1以降) / macOS 14以降（26+推奨）
  • メモリ16GB最低・24GB+推奨・32GB+保証（v0.3.1検証済み）・人物は40GB+快適
  • 容量: 普通~20GB / 人物フル~60GB（モデル＋作業領域）
  • ad-hoc署名・未公証のため初回は許可が必要です

CLI例

3dfm status
3dfm submit --mode normal -i img.png
3dfm storage status
3dfm storage move-models /Volumes/SSD/3DFM-models
3dfm models ensure --tier human
