ターミナルを、タイルで並べる。

Humi は、複数のターミナルセッションを1枚のウィンドウにタイルとして並べる macOS アプリです。＋ を押してフォルダを選ぶと、そのフォルダで開いたセッションがタイルとして表示されます。セッションはいくつでも追加できます。

最新版をダウンロード GitHub でソースを見る

無料・オープンソース（MIT） · 開発者: 折田悠希（おりたゆうき / Yuki_Orita）

使い方

＋ から3ステップ

ウィンドウの ＋ は空の状態でも、セッションがいくつ開いていても常に表示されます。

  1. ＋ を押す

    ツールバーの ＋（または ⌘N）。「そのまま開く／フォルダを選んで開く」を選ぶシートが出ます。

  2. 開き方を選ぶ

    そのまま開けばホームで、「フォルダを選んで開く」ならフォルダを指定して起動します。プロファイルも選べます。

  3. タイルで開く

    選んだ場所で起動したターミナルが、ウィンドウ内のタイルに表示されます。ペインが縦長なら上下、横長なら左右に分割されます。

機能

1枚のウィンドウに、必要なだけ

ターミナルは SwiftTerm による内蔵エミュレータ（実 PTY・実シェル）です。

v1.3: 安定性と操作性
タイル閉じ→即終了の孤児シェル、出力トリガー時のフラッド、テキスト編集中のショートカット横取りなどを修正。カスタムコントロールにホバー／キーボードフォーカスリング（高コントラスト）を整備、「コントラストを上げる」対応。⌃⌘] / ⌃⌘[ でペインをキーボードリサイズ。
v1.2: 分割ペインとウィンドウ配置
ペインを H/V に自由分割（⌘D / ⌘⇧D）、⌘⌃＋矢印でフォーカス移動、分割線ドラッグで比率変更。ペインツリー・セッション・ウィンドウ位置をまとめて保存／復元。グローバル切替ホットキー、長時間コマンド完了・ベル・出力一致の通知、正規表現トリガー、fish の OSC 7。
v1.1: 多言語・テーマ・プロファイル
日本語 / English / 中文 / Português / Español（OS 言語で自動）。6 テーマ + 自作テーマ + Light/Dark/System、⌘F 検索、URL・パス連携、シェル/環境変数/起動コマンドをまとめたプロファイルとランチャー、ショートカット変更、Git 表示付きステータスバー。
タイルの並び
入る数だけ列にリフロー。各タイルは最大化・復帰ができ、独立して動きます。
セッション無制限
＋ はどの状態でも表示。追加順にタイルが増えていきます。
フォルダで開く
選んだフォルダを作業ディレクトリにして起動。「そのまま開く」でホームでも。
バッファクリア
⌘K でフォーカス中のセッションの画面とスクロールバックを消去。プロンプトと入力中のコマンドは残ります。
再起動
シェルが終了したタイルは、同じフォルダでワンクリック再起動。
メモ欄
Markdown 対応のスクラッチメモを右側に。用途ごとにタブで分けられ、アプリを再起動しても内容は残ります。プレビュー表示ではコードブロックをワンクリックでコピー。すべてのメモを ZIP で書き出して別の端末の Humi と共有できます。
シェル設定
ログインシェル / zsh / bash / fish / カスタム（実行パス＋引数）。-l の有無も選べます。
確実な終了
アプリ終了時、すべての子シェルを同期的に停止（SIGTERM→SIGKILL→回収）。孤児プロセスを残しません。
復元
セッションの一覧とメモは次回起動時に復元。フォルダが消えていればホームで開き直します。

動作環境とビルド

macOS 14 以降

動作環境

  • ◆ macOS 14.0 以降（Apple Silicon / Intel）
  • ◆ ad-hoc 署名。初回起動は「システム設定 › プライバシーとセキュリティ」から許可
  • ◆ v1.0 は内蔵ターミナルエミュレータのみ

ソースからビルド（Xcode 不要）

git clone https://github.com/oriyu90/humi
cd humi
bash Scripts/build-app.sh release
open dist/Humi.app
