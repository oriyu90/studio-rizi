把终端，平铺排开。

Humi 是一款 macOS 应用，把多个终端会话作为图块并排放在同一个窗口里。按下 + 选择文件夹，会话就在该文件夹中启动，以图块显示。会话数量不限。

用法

从 + 开始的三步

无论窗口是空的还是已经打开了多个会话，窗口上的 + 始终可见。

  1. 按下 +

    工具栏的 +（或 ⌘N）会打开 Finder 文件夹选择器。

  2. 选择文件夹

    选择会话的工作目录。取消则在主目录中打开。

  3. 以图块打开

    选择“在此文件夹中打开”，在该处启动的终端便会作为图块显示在窗口中。

功能

一个窗口，够用就好

终端是通过 SwiftTerm 的内置模拟器（真实 PTY、真实 shell）。

图块布局
按可容纳的列数自动重排。每个图块可最大化、还原，彼此独立运行。
会话不限
+ 在任何状态下都显示；图块按添加顺序增加。
在文件夹中打开
以所选文件夹作为工作目录启动，也可“按原样打开”进入主目录。
清空缓冲
⌘K 清除当前会话的屏幕与回滚缓冲，保留提示符和正在输入的命令。
重启
shell 已退出的图块可一键在原文件夹中重启。
备忘栏
右侧的 Markdown 速记栏。重启应用后内容仍在。
Shell 设置
登录 shell / zsh / bash / fish / 自定义（路径 + 参数），可选 -l。
干净退出
退出时同步停止所有子 shell（SIGTERM → SIGKILL → 回收），不留孤儿进程。
恢复
会话列表与备忘在启动时恢复；文件夹已删除的会话会改在主目录中打开。

系统要求与构建

macOS 14 及以上

系统要求

  • ◆ macOS 14.0 及以上（Apple Silicon / Intel）
  • ◆ ad-hoc 签名——首次启动请在“系统设置 › 隐私与安全性”中允许
  • ◆ v1.0 仅提供内置模拟器

从源码构建（无需 Xcode）

git clone https://github.com/oriyu90/humi
cd humi
bash Scripts/build-app.sh release
open dist/Humi.app
