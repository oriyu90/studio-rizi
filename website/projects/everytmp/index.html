Macの熱を、xx°Cでひと目に。

EveryTMP は、Apple Silicon MacのCPU/GPU温度をメニューバーに常時表示する軽量ユーティリティです。SMCから読み取り専用で取得するため、管理者権限も常駐デーモンも不要。ドックには表示されません。

使い方

入れて、開いて、終わり

設定は不要です。起動した瞬間からメニューバーに温度が表示されます。

  1. ダウンロードして起動

    GitHub Releases から DMG をダウンロードし、アプリケーションフォルダへコピーして起動します。メニューバーに現在の温度が表示されます。

  2. 表示を選ぶ

    メニューから CPU / GPU / 高い方（両者の最大値）を切り替えられます。更新間隔も 1 / 2 / 5 / 10秒から選べます。

  3. あとは常駐

    「ログイン時に開く」をONにすれば、Macを使うあいだずっと温度を見守ります。1年間の連続稼働を想定した自己回復設計です。

機能

軽量に、安全に、正確に

温度の読み取りだけに特化し、余計なものは一切持ちません。

メニューバーにxx°C表示
現在の温度を等幅フォントで常時表示。ツールチップとメニューにはCPU/GPUの両方を表示します。
CPU / GPU / 高い方
表示対象はCPUダイ・ホットスポット、GPUダイ・ホットスポット、または両者の最大値から選択できます。
読み取り専用SMCアクセス
powermetricsのような管理者権限も、特権デーモンも不要。書き込み経路を持たない設計のため、ファン制御のような危険な操作は原理的にできません。
駐車センサーの除外
アイドル中のコアが返す番兵値や範囲外の値は表示せず、次の候補キーへ自動フォールバックします。読めない機種では--°Cと表示します。
1年稼働の自己回復
全キー連続失敗時のSMC再接続、スリープ復帰後の即時再読、メニューの都度再構築、ログ無蓄積。置きっぱなしで壊れません。
軽量設計
単一プロセス・ドック非表示。ポーリングは最短1秒・1回数ミリ秒、タイマーは省電力のためコアレッシングします。
診断ウィンドウ
取得元SMCキー・接続状態・システム情報を表示。不具合報告は--probeコマンドの出力そのまま送れます。
ログイン時起動
SMAppServiceを使い、ログイン時に自動で常駐します（メニューからワンクリックで切替）。
日本語 / English
UIは日本語と英語に完全対応しています（システム言語で自動切替、切替も再起動不要）。

動作環境とビルド

macOS 13 以降・Apple Silicon

動作環境

  • ◆ macOS 13 Ventura以降・Apple Silicon搭載Mac（M1〜M5。macOS 26.4・M3 Ultraで実機検証済み）
  • ◆ Intel Macでは取得できない場合--°Cと表示します（クラッシュしません）
  • ◆ ad-hoc 署名（未公証）。初回起動は「システム設定 › プライバシーとセキュリティ」から許可

ソースからビルド（Xcode 不要）
