Mac 的温度，一眼可见：xx°C。

EveryTMP 是一款轻量工具，在菜单栏常驻显示 Apple Silicon 的 CPU/GPU 温度。它以只读方式访问 SMC，无需管理员权限与常驻守护进程，也不会出现在程序坞中。

使用方法

安装、打开，完成

无需任何设置，启动瞬间温度即出现在菜单栏中。

  1. 下载并启动

    从 GitHub Releases 下载 DMG，复制到应用程序文件夹并启动，当前温度即显示在菜单栏中。

  2. 选择显示内容

    可在菜单中切换 CPU / GPU / 取高值（两者最大值），刷新间隔也可选择 1 / 2 / 5 / 10 秒。

  3. 保持常驻

    打开“登录时启动”，使用 Mac 的全程都有温度守望。按可连续运行一年设计，具备自恢复能力。

功能

轻量、安全、准确

只专注于读取温度，不携带任何多余的东西。

菜单栏 xx°C 显示
以等宽字体常驻显示当前温度，悬浮提示与菜单中同时显示 CPU/GPU 两路数值。
CPU / GPU / 取高值
可在 CPU 芯片热点、GPU 芯片热点或两者最大值之间选择显示对象。
只读 SMC 访问
不需要 powermetrics 那样的管理员权限，也没有特权守护进程。设计上不存在写入路径，风扇控制等危险操作在原理上不可能发生。
排除停放传感器
空闲核心返回的哨兵值与超范围读数一律不显示，自动回退到下一个候选键；不支持的机型显示 --°C。
为一年运行自恢复
全键连续失败时重连 SMC，睡眠唤醒后立即重读，每次打开菜单都重建，零日志堆积，可放心长期放置。
轻量设计
单进程、不占程序坞。轮询最短 1 秒、单次读取仅数毫秒，定时器经过合并以节省电量。
诊断窗口
显示数据来源 SMC 键、连接状态与系统信息，反馈问题时直接发送 --probe 命令输出即可。
登录时启动
使用 SMAppService 注册，登录后自动常驻（菜单中一键开关）。
日本語 / English
界面完整支持日语与英语（跟随系统语言，切换无需重启）。

运行环境与构建

macOS 13 及更高版本 · Apple Silicon

运行环境

  • ◆ macOS 13 Ventura 及更高版本 · Apple Silicon Mac（M1–M5，已在 macOS 26.4 / M3 Ultra 真机验证）
  • ◆ Intel Mac 无法读取时显示 --°C（不会崩溃）
  • ◆ 即兴签名（未公证）。首次启动请前往“系统设置 › 隐私与安全性”放行
