Fotos, música, documentos —
num só lugar

O Media Master é um gerenciador de mídia e arquivos Android de código aberto que mantém fotos, vídeos, música, documentos, armazenamento, apps e arquivos em pastas de rede num único app. Sem conta, sem cadastro — funciona na hora.

Ver o código no GitHub Ver instruções de build

A v0.3.0 reconstrói a interface sobre o Material 3 com contraste verificado em WCAG AA, adiciona o esquema mediamaster:// para outros apps abrirem qualquer recurso e adiciona armazenamento de rede SMB / WebDAV.

Organize o conteúdo do aparelho sem caçar menus.

De navegar por fotos e vídeos a tocar música, digitalizar documentos, limpar o armazenamento e gerenciar apps. Na v0.3.0, cada recurso está a um toque da tela inicial.

LIBRARY
Fotos e vídeos, por álbum
Todas as imagens e vídeos do aparelho em grade, mais uma visão de álbuns agrupada por pasta. Toque para ver em tela cheia ou abra o editor ali mesmo.
AUDIO
Música, em faixas e listas
Reprodução em segundo plano com o Media3 (ExoPlayer). A posição do mini player agora vem de callbacks do player, não de um laço de polling.
SCAN & DOCS
Digitalize documentos em PDF
Integra o GMS Document Scanner para transformar papel em PDF ou JPEG na hora.
MANAGE
Organize armazenamento e apps
Navegue direto pelo armazenamento interno e externo, filtre por categoria, detecte arquivos duplicados por hash e gerencie apps instalados e APKs.
EDIT
Edite imagens e vídeos
Cortar, girar e ajustar cor de imagens; cortar e silenciar vídeos. Abra o editor pelo visualizador ou pelo "Editar com" de outro app.
BACKUP
Backups agendados
Um motor de backup baseado em WorkManager que arquiva pastas-alvo em ZIP conforme suas condições (carregando, Wi-Fi). A restauração tem proteção contra path traversal.

Outros apps podem abrir um recurso pelo nome.

O Media Master expõe um ponto de entrada para cada recurso por meio de um esquema mediamaster:// dedicado. Ele não é marcado como BROWSABLE, então uma página web não consegue acioná-lo — só um app do aparelho que monta a intent explicitamente. Ele também se registra nos seletores "Abrir com" e "Editar com" do sistema.

  • mediamaster://library / audio / documents / manage / apps / clean / settings
  • mediamaster://browse?path=/storage/emulated/0/Download — navegador de arquivos num caminho absoluto
  • mediamaster://edit/image?uri=… / edit/video?uri=… — editores de imagem e vídeo
  • ACTION_EDIT (imagem, vídeo) e ACTION_VIEW (mídia, pastas) também são suportados

Pedidos desconhecidos ou malformados apenas abrem o app normalmente. Ações destrutivas — apagar, desinstalar, restaurar backup — nunca são executadas a partir de uma intent externa.

Arquivos SMB / WebDAV, na mesma tela.

Adicione compartilhamentos SMB e servidores WebDAV em Configurações → Conexão de servidor, então navegue pelas pastas remotas e entregue arquivos ao seletor "Abrir com" do sistema. As senhas são guardadas com EncryptedSharedPreferences (AES-256, chave no Android Keystore) — nunca em texto puro.

Toda chamada de rede roda fora da thread principal com timeouts de conexão e leitura; host inacessível, senha errada ou timeout mostram um erro em vez de travar.

Em telas grandes, uma interface desktop estilo Finder.

Ela troca automaticamente apenas quando o Android informa modo DeX / desktop — não em tablets grandes comuns nem no modo paisagem. Uma barra lateral à esquerda percorre Início, Biblioteca, Áudio, Documentos, Gerenciar, Apps, Configurações e Armazenamento de rede, e pastas podem ser fixadas na barra por arrastar e soltar.

  • Uma lista de dispositivos com armazenamento interno, externo e de rede
  • Pictures / Download / apk fixados por padrão
  • Pressione e segure, clique com o botão direito ou use o botão de overflow da linha para "Abrir em nova aba", "Fixar" e "Desafixar"

Cinco idiomas, string a string.

Inglês, japonês, chinês simplificado, árabe (RTL) e holandês carregam o mesmo número de chaves de string. Quantidades usam <plurals>, com as seis categorias do árabe. Troque pela configuração no app ou pela configuração de idioma por app do Android 13+.

Teste o APK assinado agora mesmo.

O Media Master v0.3.0 está disponível como APK assinado no GitHub Releases. Esta versão adiciona a API de acesso externo, o armazenamento de rede SMB/WebDAV e a interface Material 3.

Obter ou compilar

  1. 1Baixe e instale o APK assinado do GitHub Releases.
  2. 2Para compilar do código, clone o repositório no GitHub e abra no Android Studio.
  3. 3Tenha o Android SDK 36 e o JDK 21 (o nível de compatibilidade de origem é Java 17).
  4. 4Rode ./gradlew :app:assembleDebug num terminal, ou execute pelo Android Studio.

Detalhes de build e assinatura no README

Requer Android 7.0 (API 24) ou posterior. O acesso à mídia usa o MediaStore / Storage Access Framework padrão do Android.
