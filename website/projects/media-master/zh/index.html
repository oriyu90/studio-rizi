照片、音乐、文档，
都在一处

Media Master 是一款开源的 Android 媒体与文件管理应用，把照片、视频、音乐、文档、存储、应用以及网络共享上的文件放进同一个应用。无需账号、无需注册，打开即用。

在 GitHub 查看源码 查看构建方法

v0.3.0 将界面全面重构到 Material 3，并按 WCAG AA 校验对比度；新增 mediamaster:// 方案，让其他应用直接打开任一功能，并新增 SMB / WebDAV 网络存储。

  • 系统Android 7.0 及以上
  • 语言五种
  • 许可MIT / 免费

整理设备内容，不必层层翻找。

从浏览照片和视频，到播放音乐、扫描文档、清理存储和管理应用。v0.3.0 中，每项功能都能从主屏幕一键直达。

LIBRARY
照片与视频，按相册
以网格展示设备上的全部图片与视频，并提供按文件夹分组的相册视图。点按即可全屏查看，或就地打开编辑器。
AUDIO
音乐，按曲目与播放列表
基于 Media3（ExoPlayer）的后台播放。迷你播放器的进度改由播放器回调更新，不再依赖轮询。
SCAN & DOCS
扫描文档为 PDF
集成 GMS 文档扫描器，随手把纸质文档数字化为 PDF 或 JPEG。
MANAGE
整理存储与应用
直接浏览内部与外部存储，按类别筛选，用哈希检测重复文件，并管理已安装应用与 APK。
EDIT
编辑图片与视频
图片裁剪、旋转、调色；视频裁剪与静音。可从查看器的“编辑”，或从其他应用的“用其他应用编辑”打开。
BACKUP
计划备份
基于 WorkManager 的备份引擎，按条件（充电、Wi-Fi）将目标文件夹归档为 ZIP。恢复过程已做路径穿越防护。

其他应用可按名称打开某项功能。

Media Master 通过专用的 mediamaster:// 方案公开各功能入口。它未标记 BROWSABLE，因此网页无法触发，只有设备上明确构造该意图的应用才能调用。它同时注册到系统的“用其他应用打开 / 编辑”选择器。

  • mediamaster://library / audio / documents / manage / apps / clean / settings
  • mediamaster://browse?path=/storage/emulated/0/Download — 按绝对路径打开文件浏览器
  • mediamaster://edit/image?uri=… / edit/video?uri=… — 图片与视频编辑器
  • 同时支持 ACTION_EDIT（图片、视频）与 ACTION_VIEW（媒体、文件夹）

未知或格式不正确的请求只会正常打开应用。删除、卸载、从备份恢复等破坏性操作绝不会由外部意图触发。

SMB / WebDAV 的文件，也在同一界面。

在“设置 → 服务器连接”中添加 SMB 共享和 WebDAV 服务器，即可浏览远程文件夹，并把文件交给系统的“用其他应用打开”。密码使用 EncryptedSharedPreferences（AES-256，密钥存于 Android Keystore）加密保存，绝不以明文存储。

所有网络请求均在主线程之外执行，带有连接与读取超时；主机不可达、密码错误或超时都会显示错误而非崩溃。

在大屏上，切换为 Finder 风格的桌面界面。

仅当 Android 报告 DeX / 桌面模式时才会自动切换，普通大屏平板或横屏不会触发。左侧边栏可在主页、库、音频、文档、管理、应用、设置与网络存储间切换，文件夹可通过拖放固定到侧边栏。

  • 包含内部、外部与网络存储的设备栏
  • 默认固定 Pictures / Download / apk
  • 长按、右键或行尾按钮可“在新标签页打开”“固定”“取消固定”

五种语言，逐条字符串对齐。

英语、日语、简体中文、阿拉伯语（RTL）与荷兰语的字符串键数量完全一致。数量表达使用 <plurals>，阿拉伯语覆盖全部六个分类。可在应用内设置切换，也可在 Android 13+ 的按应用语言设置中切换。

  • English
  • 日本語
  • 简体中文
  • العربية
  • Nederlands

立即试用已签名的 APK。

Media Master v0.3.0 以已签名 APK 的形式发布于 GitHub Releases。本次更新加入了应用互通 API、SMB/WebDAV 网络存储与 Material 3 新界面。

获取或自行构建

  1. 1从 GitHub Releases 下载并安装已签名的 APK。
  2. 2如需从源码构建，克隆 GitHub 仓库并用 Android Studio 打开。
  3. 3准备 Android SDK 36 与 JDK 21（源码兼容级别为 Java 17）。
  4. 4在终端运行 ./gradlew :app:assembleDebug，或从 Android Studio 运行。

在 README 查看构建与签名细节

需要 Android 7.0（API 24）及以上。媒体访问使用 Android 标准的 MediaStore / 存储访问框架。
