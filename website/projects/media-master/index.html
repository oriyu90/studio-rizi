Media Masterは、写真・動画・音楽・書類・ストレージ・アプリ・ネットワーク上のファイルを1つのアプリでまとめて管理できる、Android向けのオープンソースなメディア・ファイルマネージャーです。登録もアカウントも不要で、すぐに使い始められます。

端末の中身を、迷わず片づける。

写真や動画の閲覧から、音楽の再生、書類のスキャン、ストレージの整理、アプリ管理まで。v0.3.0ではホーム画面からすべての機能へ直接移動できます。

LIBRARY
写真・動画をアルバムで
端末内の全画像・動画をグリッド表示。保存先フォルダごとのアルバムビューにも対応し、タップでフルスクリーン再生・閲覧、その場で編集画面へ進めます。
AUDIO
音楽をトラック・プレイリストで
Media3(ExoPlayer)によるバックグラウンド再生。ミニプレーヤーの再生位置はリスナー駆動で正確に更新されます。
SCAN & DOCS
書類をスキャンしてPDFに
GMS Document Scannerと連携し、紙の書類をその場でPDFやJPEGへデジタル化できます。
MANAGE
ストレージとアプリを整理
内部/外部ストレージを直接ブラウジングし、カテゴリ別フィルタ、重複ファイルのハッシュ検出、インストール済みアプリ・APKの管理をまとめて行えます。
EDIT
画像・動画の編集
画像のクロップ・回転・色調整、動画のトリムとミュート。ビューアの「編集」からも、他アプリの「編集」からも開けます。
BACKUP
スケジュールバックアップ
WorkManagerベースのバックアップエンジン。充電中やWi-Fi接続時のみなど条件を指定して、対象フォルダをZIPへ自動アーカイブします。復元はパストラバーサル対策済み。

他のアプリから、機能を名指しで開ける。

Media Master は専用の mediamaster:// スキームで各機能への入口を公開します。BROWSABLE を付けていないため、Webページからは起動できず、端末上のアプリが明示的に呼び出したときだけ動作します。標準の「アプリで開く」「編集」にも登録されます。

  • mediamaster://library / audio / documents / manage / apps / clean / settings
  • mediamaster://browse?path=/storage/emulated/0/Download — 絶対パスのファイルブラウザ
  • mediamaster://edit/image?uri=… / edit/video?uri=… — 画像・動画エディタ
  • ACTION_EDIT(画像・動画) / ACTION_VIEW(メディア・フォルダ) にも対応

未知・不正なリクエストは通常どおりアプリを開くだけ。削除・アンインストール・バックアップ復元などの破壊的操作が外部から実行されることはありません。

SMB / WebDAV のファイルも、同じ画面で。

設定 → サーバー接続 から SMB 共有・WebDAV サーバーを登録すると、リモートのフォルダを閲覧し、ファイルをシステムの「アプリで開く」に渡せます。パスワードは EncryptedSharedPreferences(AES-256、鍵は Android Keystore)で暗号化保存し、平文では保存しません。

すべての通信は接続・読み取りタイムアウト付きでメインスレッド外で実行され、接続失敗・認証エラー・タイムアウトはクラッシュせずエラー表示になります。

大画面では、Finder風のデスクトップUIに。

Android が DeX / デスクトップモードを返した場合だけ自動で切り替わります。通常の大画面タブレットや横画面では切り替わりません。左サイドバーからホーム・ライブラリ・オーディオ・ドキュメント・管理・アプリ・設定・ネットワークストレージへ移動でき、フォルダはドラッグ&ドロップでサイドバーへピン留めできます。

  • 内部ストレージ・外部ストレージ・ネットワークストレージの端末欄
  • Pictures / Download / apk を標準ピン留め
  • 長押し・右クリック・末尾ボタンから「新しいタブで開く」「ピン留め」「ピン解除」

5言語、すべての文字列キーを同数で。

英語・日本語・簡体字中国語・アラビア語(RTL)・オランダ語の全言語で同数の文字列キーを揃えています。数量表現は <plurals> で扱い、アラビア語は6分類に対応。アプリ内設定に加え、Android 13以降のシステム言語設定からも切り替えられます。

署名済みAPKをすぐ試せます。

Media Master v0.3.0はGitHub Releasesから署名済みAPKを入手できます。外部連携API、SMB/WebDAVネットワークストレージ、Material 3ベースの新UIを追加しました。

入手・ビルド

  1. 1GitHub Releasesから署名済みAPKをダウンロードしてインストールします。
  2. 2ソースから試す場合はGitHubリポジトリをクローンし、Android Studioで開きます。
  3. 3Android SDK 36 と JDK 21(ソース互換性はJava 17)を用意します。
  4. 4ターミナルで ./gradlew :app:assembleDebug を実行するか、Android Studioから実行します。

READMEでビルド・署名の詳細を見る

対応OSはAndroid 7.0(API 24)以降です。メディアへのアクセスにはAndroid標準のMediaStore / Storage Access Frameworkを使用します。
