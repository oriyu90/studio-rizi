Photos, music, documents —
in one place

Media Master is an open-source Android media and file manager that keeps photos, video, music, documents, storage, apps and files on network shares in a single app. No account, no sign-up — it works straight away.

View the source on GitHub See build instructions

v0.3.0 rebuilds the UI on Material 3 with WCAG AA contrast, adds the mediamaster:// scheme so other apps can open any feature directly, and adds SMB / WebDAV network storage.

Tidy up your device without hunting for menus.

From browsing photos and video to playing music, scanning documents, cleaning storage and managing apps. In v0.3.0 every feature is one tap away from the home screen.

LIBRARY
Photos and video, by album
Every image and video on the device in a grid, plus an album view grouped by folder. Tap for full-screen viewing, or open the editor in place.
AUDIO
Music, as tracks and playlists
Background playback with Media3 (ExoPlayer). The mini player's position now updates from player callbacks rather than a polling loop.
SCAN & DOCS
Scan documents to PDF
Integrates the GMS Document Scanner to turn paper documents into PDF or JPEG on the spot.
MANAGE
Organise storage and apps
Browse internal and external storage directly, filter by category, detect duplicate files by hash, and manage installed apps and APKs.
EDIT
Edit images and video
Crop, rotate and colour-adjust images; trim and mute video. Open the editor from the viewer, or from another app's "Edit with".
BACKUP
Scheduled backups
A WorkManager-based backup engine that archives target folders to ZIP under your constraints (charging, Wi-Fi). Restore is guarded against path traversal.

Other apps can open a feature by name.

Media Master exposes an entry point to every feature through a dedicated mediamaster:// scheme. It is not marked BROWSABLE, so a web page cannot trigger it — only an app on the device that builds the intent explicitly. It also registers for the system "Open with" and "Edit with" choosers.

  • mediamaster://library / audio / documents / manage / apps / clean / settings
  • mediamaster://browse?path=/storage/emulated/0/Download — file browser at an absolute path
  • mediamaster://edit/image?uri=… / edit/video?uri=… — image and video editors
  • ACTION_EDIT (image, video) and ACTION_VIEW (media, folders) are supported too

Unknown or malformed requests simply open the app normally. Destructive actions — delete, uninstall, restore-from-backup — are never performed from an external intent.

SMB / WebDAV files, in the same screen.

Add SMB shares and WebDAV servers under Settings → Server connection, then browse the remote folders and hand files to the system "Open with" chooser. Passwords are stored with EncryptedSharedPreferences (AES-256, key in the Android Keystore) — never in plain text.

Every network call runs off the main thread with connect and read timeouts; a bad host, wrong password or timeout shows an error rather than crashing.

On big screens, a Finder-style desktop UI.

It switches automatically only when Android reports DeX / desktop mode — not on ordinary large tablets or in landscape. A left sidebar moves between Home, Library, Audio, Documents, Manage, Apps, Settings and Network storage, and folders can be pinned to the sidebar by drag and drop.

  • A devices list with internal, external and network storage
  • Pictures / Download / apk pinned by default
  • Long-press, right-click or the row's overflow button for "Open in new tab", "Pin" and "Unpin"

Five languages, matched string for string.

English, Japanese, Simplified Chinese, Arabic (RTL) and Dutch all carry the same number of string keys. Quantities use <plurals>, with all six categories for Arabic. Switch from the in-app setting or from the Android 13+ per-app language setting.

Try the signed APK right away.

Media Master v0.3.0 is available as a signed APK on GitHub Releases. This release adds the external-access API, SMB/WebDAV network storage and the Material 3 UI.

Get it or build it

  1. 1Download and install the signed APK from GitHub Releases.
  2. 2To build from source, clone the GitHub repository and open it in Android Studio.
  3. 3Provide Android SDK 36 and JDK 21 (the source compatibility target is Java 17).
  4. 4Run ./gradlew :app:assembleDebug from a terminal, or run from Android Studio.

Build and signing details in the README

Requires Android 7.0 (API 24) or later. Media access uses Android's standard MediaStore / Storage Access Framework.
