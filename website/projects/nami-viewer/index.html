NamiVision は、音声の全体波形と最大4本の周波数帯域波形をDAWのように並べ、BPM・拍子・小節開始から作ったグリッドに対する各帯域の立ち上がり誤差をCSVにするWindowsアプリです。

01 / LANES

MASTER + 4 BANDS

5本のレーンで、音のどこが拍に乗っているかが見える。

最上段のマスター波形で曲全体と拍グリッドを確認し、その下に低域から高域まで4本の帯域波形を並べます。帯域は設定で1〜4本に変更でき、表示範囲も自由に調整できます。

  • 96の対数帯域から、選んだ4帯域を波形として合成。低域のキック、中域のスネア、高域のハイハットを別々に見分けられます。
  • 拍グリッドと小節番号をルーラーに表示。小節開始フラグはレーン内でドラッグでき、1 ms単位で調整できます。
  • 再生ヘッドと波形は同じタイムラインで動きます。聴きながら、ズレが大きい拍をその場で特定できます。

02 / WORKFLOW

LOAD → GRID → CSV

3ステップで、拍のズレをCSVへ。

特別なプロジェクト作成は不要です。音源を開き、テンポを合わせ、帯域レーンを右クリックするだけ。

01

音源を開く

mp3 / wav / flac / ogg に対応。5秒以上の音声をドラッグ＆ドロップするか、ヘッダーの「開く」から選びます。解析はRust側で実行され、UIは待たされません。

MP3WAVFLACOGG5秒以上
02

テンポを合わせる

マスターレーンを右クリックしてBPM・拍子・小節開始を設定。数値入力のほか、4回以上のタップからBPMを求められます。小節開始はルーラー上の「1」フラグをドラッグして微調整できます。

BPM 20–4002 / 3 / 4 / 6 / 8Tap tempoDrag bar start
03

帯域レーンからCSV出力

各帯域レーンを右クリックし、「拍のずれを CSV 出力」を選びます。テンポ未設定時は項目が無効化され、先に設定すべき内容がフッターに表示されます。

Right-clickCSVBOM + CRLF
03 / CSV

MEASURE, DON'T GUESS

数字は、そのまま検証できる形で。

CSVは1拍1行。期待時刻、検出したオンセット時刻、その差（ms / 拍比）、オンセット強度、検出状態を帯域ごとに出力します。Excelでそのまま開けるよう、UTF-8 BOMとCRLFで保存します。

差が正なら拍より遅く、負なら早く鳴っています。未検出の拍は空の測定値と undetected として残るため、どの拍を測れなかったか追跡できます。

  • + ms拍より遅いオンセット
  • − ms拍より早いオンセット
  • undetected探索窓内に十分な立ち上がりがない拍
