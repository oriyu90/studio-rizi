通过 Wi-Fi，把相机里的照片直接传到手机

α6k Transfer 可直连 Sony α6000 系列相机的 Wi-Fi，把拍摄的照片传输到手机。无需数据线，也无需云端。只需在相机上设为“从智能手机选择”→“显示中”，即可在列表中选择照片并保存到相册。

在 GitHub 查看源码 安装 APK

v1.0.0 首次发布。Material 3 Expressive 界面，支持日语／英语切换与浅色／深色主题。

功能

Wi-Fi 直传

在应用内加入相机接入点（DIRECT-…），通过 DLNA/UPnP 获取照片列表，只保存选中的照片原图。

已保存标记

相册中已有的照片会显示“已保存”，避免重复传输。还可按拍摄日期筛选。

语言与主题切换

显示语言可在日语／英语／跟随系统之间切换，主题可在浅色／深色／跟随系统之间切换，即时生效。

机型配置

α6000 已真机验证。α6100 及后续机型为预测性适配（未经验证），自动搜索会一并尝试，面向未来机型设计。

使用方法

  1. 在相机上：MENU → 发送到智能手机 → 从智能手机选择 →“显示中”
  2. 在应用的“连接”标签页点“连接＋绑定”（首次使用会出现系统确认对话框）
  3. 点“搜索相机”确认 LOCATION 后，到“传输”标签页读取列表、选择并传输
