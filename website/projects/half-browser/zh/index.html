v1.1.0 新增文件附件、摄像头、位置信息、视频全屏，以及书签页面的后台更新通知。

What it does

只保留需要的，
一个浏览器。

Half-Browser 以 Android WebView 作为页面引擎，让打开网页、保存书签、确认证书这些日常操作保持简单。没有广告和分析，外观也可以按您的喜好调整。

01HTTPS

自签名 HTTPS 页面，确认后再打开。

对于家庭局域网服务器等证书并非由公共机构签发的页面，您可以查看主机、签发者、SHA-256 指纹与有效期，然后选择“仅此一次信任”或“始终信任此站点”。

02LOGIN

HTTP 认证，加密保存并自动填充。

输入的 Basic 与 Digest 认证用户名和密码可以保存，下次自动填充。凭据使用 Android Keystore 和 EncryptedSharedPreferences 加密，并排除在 Android 备份之外。

03HOME

书签以带图标的磁贴显示。

书签在主页以网格排列。图标为离线生成的文字单色图标。长按磁贴即可编辑、删除、分享，或添加到桌面快捷方式。

04DEFAULT

作为默认浏览器接收外部链接。

在 Android 设置中选择 Half-Browser 为默认浏览器后，它会接收其他应用打开的链接。若该网址已加入书签，会在顶部显示书签名称的专用栏后再打开。

05THEME

深色、浅色，或跟随系统。

可选择深色、浅色或跟随系统主题。在支持的设备上还可以使用动态取色。

06SIZE

手机与平板都易读。

界面缩放可调为 80%–140%，文字缩放为 80%–150%。网格列数可选自动、3、4、5、6 或 8。支持横屏。

Self-signed HTTPS

先查看证书，
再决定是否信任。

证书不受信任时，Half-Browser 会说明原因并提供可查看的详情。判断权在您手中。

  1. 01 阅读警告

    显示主机名以及证书不受信任的原因，例如并非由公共机构签发。

  2. 02 查看详情

    打开“证书详情”，可确认签发者、SHA-256 指纹和有效期。

  3. 03 选择范围

    选择“仅此一次信任”或“始终信任此站点”。信任按主机与证书的组合分别保存。

  4. 04 变更后重新确认

    证书变化时会再次询问。您可以随时在设置中撤销对某站点的信任。

HTTP authentication

凭据在设备内受到保护。

HTTP 认证（Basic 与 Digest）的用户名和密码保存在 EncryptedSharedPreferences 中，使用由 Android Keystore 持有的密钥加密。未加密的 HTTP 连接不会保存凭据。

可随时在设置中删除已保存的凭据。这些数据也已排除在 Android 备份之外。

Home and bookmarks

把常用页面，
排成磁贴。

主页由搜索框和书签网格组成。轻点磁贴即可打开页面，长按则可整理。

  • 图标磁贴离线生成的文字单色图标，可编辑为喜欢的名称与图标。
  • 长按操作编辑、删除、添加主屏幕快捷方式与分享，都在一个菜单中完成。
  • 快捷方式确认添加到桌面前会先弹出确认步骤。
  • 网格列数可在自动、3、4、5、6、8 列之间选择，适合屏幕宽度。

Default browser

设为默认，
即可接收链接。

在 Android 中，默认浏览器由用户在系统设置里选择。选择 Half-Browser 后，它会接收其他应用打开的外部链接。若网址已加入书签，会在顶部显示书签名称的专用栏后再打开。

Display and language

适配屏幕，
便于阅读。

支持手机、平板与横屏。调整文字和界面大小时，主页与设置页面仍保持清晰的布局。

  • 手机・竖屏

    搜索框与书签自上而下排列，单手也便于操作。

  • 手机・横屏

    横屏下书签网格与浏览界面同样可以使用。

  • 平板

    在更宽的屏幕上，书签磁贴依然易于阅读。

界面支持日语与英语，并跟随设备的语言设置显示。

Get started

从 GitHub 获取 v1.1.0。

Half-Browser 的源代码在 GitHub 公开，最新版本可从 GitHub Releases 获取。

打开 Releases
  1. 打开仓库 github.com/oriyu90/half-browser。
  2. 从 Releases 下载最新 APK，并安装到 Android 设备上。
  3. 若要接收外部链接，请在 Android 设置中将 Half-Browser 设为默认浏览器。
  4. 若要从源代码构建，请克隆仓库并用 Android Studio 打开。

需要 Android 8.0（API 26）及以上。从 Play 商店以外安装 APK 时，可能需要允许安装未知来源的应用。
