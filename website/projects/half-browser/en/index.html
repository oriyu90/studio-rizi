Half-Browser / ハーフブラウザKeep the pages you trust
close at hand.

Half-Browser is a lightweight browser built on Android WebView (Chromium). For HTTPS pages signed with a self-signed certificate, you review the certificate details before choosing whether to trust it. HTTP authentication credentials are stored encrypted with Android Keystore and can be autofilled next time. No ads, no analytics, no accounts.

What it does

Only what you need,
in a browser.

Half-Browser uses Android WebView for its page engine and keeps the everyday tasks simple: open a page, keep bookmarks, and check certificates. There are no ads or analytics, and you can adjust the look to suit you.

01HTTPS

Open self-signed HTTPS pages after checking them.

For pages such as a home LAN server that use a certificate not issued by a public authority, you can review the host, issuer, SHA-256 fingerprint, and expiry date, then choose "Trust once" or "Always trust this site".

02LOGIN

HTTP authentication, stored encrypted and autofilled.

Basic and Digest credentials you enter can be saved and filled in automatically next time. They are encrypted with Android Keystore and EncryptedSharedPreferences and are excluded from Android backup.

03HOME

Bookmarks as icon tiles.

Bookmarks appear as a grid on the home screen. Each tile has an offline-generated monogram icon. Long-press a tile to edit, delete, share, or add a launcher shortcut.

04DEFAULT

Receive external links as your default browser.

Choose Half-Browser as the default browser in Android settings and it receives links opened from other apps. If the URL is already bookmarked, it opens with a bar showing the bookmark name.

05THEME

Dark, light, or following the system.

Choose dark, light, or system theme. On supported devices you can also use dynamic color.

06SIZE

Comfortable on phones and tablets.

Adjust UI scale from 80% to 140% and text scale from 80% to 150%. Choose the grid column count: auto, 3, 4, 5, 6, or 8. Landscape is supported.

Self-signed HTTPS

Check the certificate,
then decide to trust it.

When a certificate is not trusted, Half-Browser explains why and gives you the details to inspect. The decision stays with you.

  1. 01 Read the warning

    The host name and the reason the certificate is not trusted, such as not being issued by a public authority, are shown.

  2. 02 Review the details

    Open "Show certificate details" to check the issuer, the SHA-256 fingerprint, and the expiry date.

  3. 03 Choose the scope

    Pick "Trust once" or "Always trust this site". Trust is stored for the exact combination of host and certificate.

  4. 04 Asked again when it changes

    If the certificate changes, you are asked again. You can revoke a trusted site at any time from Settings.

HTTP authentication

Credentials stay protected on your device.

HTTP authentication (Basic and Digest) usernames and passwords are saved in EncryptedSharedPreferences, encrypted with a key held in Android Keystore. Credentials are not saved over unencrypted HTTP.

You can delete saved credentials at any time from Settings. They are also excluded from Android backup.

Home and bookmarks

Arrange the pages you use
as tiles.

The home screen has a search field and a grid of bookmarks. Tap a tile to open the page, and long-press to organize.

  • Icon tilesMonogram icons generated offline. Edit them to change the name and icon.
  • Long-press actionsEdit, delete, add a home-screen shortcut, and share from one menu.
  • Shortcut confirmationA confirmation step appears before a shortcut is added to the launcher.
  • Grid columnsChoose auto, 3, 4, 5, 6, or 8 columns to suit the screen width.

Default browser

Set it as default
to receive links.

On Android, you choose the default browser in the system settings. Once Half-Browser is selected, it receives external links opened from other apps. If a URL is already bookmarked, it opens with a bar showing the bookmark name.

Display and language

Fits your screen,
and easy to read.

Works on phones, tablets, and in landscape. The home and settings screens are laid out to stay clear as you change the text and UI sizes.

  • Phone, portrait

    The search field and bookmarks in order from the top, easy to use one-handed.

  • Phone, landscape

    The bookmark grid and browsing screen both work in landscape.

  • Tablet

    Bookmark tiles stay readable across the wider screen.

The UI is available in Japanese and English and follows your device language setting.

Get started

v1.0.0, from GitHub.

The Half-Browser source is published on GitHub. The latest release is available on GitHub Releases.

Open Releases
  1. Open the repository at github.com/oriyu90/half-browser.
  2. Download the latest APK from Releases and install it on your Android device.
  3. To receive external links, choose Half-Browser as the default browser in Android settings.
  4. To build from source, clone the repository and open it in Android Studio.

Requires Android 8.0 (API 26) or later. Installing an APK outside the Play Store may require allowing installs from unknown sources.
