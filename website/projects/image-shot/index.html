Image Shot / イメージショット撮った写真を、
消さずに仕上げる。

Image Shot は、Android 16 以降のための非破壊・オフライン優先の写真編集アプリです。露出や色温度、トーンカーブ、HSL、自由角度の傾き補正、局所マスクまで、調整はすべて「指示」として記録され、元の写真は書き換えません。気が変わったら、何度でも戻せます。企画名は Prism Photo（プリズムフォト）。

What it does

編集しても、
写真は減らない。

Image Shot が保存するのは、加工済みの画像ではなく調整の手順です。だから何度でもやり直せて、元の写真も、書き出した写真も、あとから同じように作り直せます。

01NON-DESTRUCTIVE

元の写真は、そのまま残る。

調整は写真そのものではなく「指示」として保存されます。履歴は追記のみで、通過した各段階の状態も保持するため、何手戻っても画質は変わりません。アプリが強制終了しても、開き直せば続きから再開できます。

02TONE

明るさと色を、数字で追い込む。

露出、コントラスト、ハイライト、シャドウ、白レベル、黒レベル、自然な彩度、彩度、色温度、色合い。スライダーに加えて数値を直接入力できるので、同じ仕上がりを別のカットにも同じ値で再現できます。

03CURVES & HSL

カーブと、8系統の HSL。

master と R / G / B のトーンカーブで階調を設計し、8系統の色相ごとに色相・彩度・明度を調整します。空の青だけ、肌の赤だけを、他の色を動かさずに補正できます。

04GEOMETRY

水平を出すために、削りすぎない。

±45°の自由角度回転と数値入力、左右・上下の反転、自由クロップ。傾き補正とトリミングを別々に扱えるので、構図を保ったまま水平だけを直せます。

05DETAIL & LOCAL

全体はディテール、一部分はマスクで。

シャープと輝度ノイズ低減で細部を整え、直線・円形・ブラシのマスクに feather をかけて、内側だけ露出や彩度を動かせます。効かせすぎないところで止められます。

06EXPORT

JPEG / PNG で、書き出し。

品質を指定して書き出し。処理はバックグラウンドで進み、保存先は端末のフォルダから選べます。EXIF は撮影日時やカメラ情報を引き継ぎ、位置情報は外して書き出します。

Six panels

調整は、6つのパネルに。

プレビューを見ながら、必要なパネルだけを開いて詰められます。どのパネルも、触った量と数値がその場で分かります。

基本調整TONE

露出、コントラスト、ハイライト、シャドウ、白レベル、黒レベル、自然な彩度、彩度、色温度、色合い。

カーブCURVES

master と R / G / B のトーンカーブ。ポイントを置いて、階調の持ち上げと沈みを直接動かします。

HSLHUE / SAT / LUM

8系統の色相ごとに、色相・彩度・明度を調整します。

ジオメトリGEOMETRY

±45°の自由角度回転、左右・上下の反転、自由クロップ。

ディテールDETAIL

シャープと輝度ノイズ低減。細部の立て方と、ざらつきの落とし方を別々に。

局部補正LOCAL

直線・円形・ブラシのマスク。feather で境目をなじませ、マスクの内側だけを補正します。

Flow

プレビューを見ながら、
詰めていく。

写真を選ぶと、すぐに編集画面へ。プレビューで仕上がりを確かめ、パネルで数値を動かす。取り消しとやり直し、履歴の件数は常に画面の下にあります。

  1. 01 取り込む

    フォトピッカーから複数枚をまとめて。ファイルやフォルダーを SAF で選ぶこともできます。

  2. 02 調整する

    6つのパネルを切り替えながら、露出・色・階調・形・局部を順に。値は数値でも入力できます。

  3. 03 見比べる

    Before/After で調整前と比較。気に入らなければ、履歴から何手でも戻せます。

  4. 04 書き出す

    JPEG か PNG を選び、品質と保存先を決めて書き出し。元の写真はそのまま残ります。

Layout

画面の広さに、合わせる。

スマートフォンの縦画面ではプレビューの下にパネル、横画面では左右に分割。タブレットは 840dp 以上で2ペインに切り替わり、写真を大きく保ったまま調整できます。

  • スマートフォン・縦

    プレビューの下にパネル。片手でも操作できます。

  • スマートフォン・横

    プレビューとパネルを左右に。写真を大きく見ながら。

  • タブレット・2ペイン

    840dp 以上で2ペイン。プレビューを保ったまま調整。

Privacy

写真は、端末から出ない。

Image Shot は INTERNET 権限を宣言していません。写真をアップロードする機能も、解析のために外部へ送る処理もありません。編集はすべて端末内で完結します。

広域ストレージ権限も要求せず、読み込みと保存は Android のフォトピッカーと SAF（Storage Access Framework）を通します。元の写真は書き換えず、書き出した JPEG / PNG からは位置情報を外します。

Get started

v0.1.0 を、GitHub から。

Image Shot のソースは GitHub で公開しています。v0.1.0 は署名済み APK として GitHub Releases で配布します。

GitHub Releases を開く
  1. GitHub のリポジトリ github.com/oriyu90/image-shot を開きます。
  2. Releases から署名済み APK を取得し、端末にインストールします。
  3. ソースから動かす場合はリポジトリをクローンし、Android Studio で開きます。
  4. Android SDK 36 と JDK を用意して ./gradlew :app:assembleDebug を実行します。

対応OSは Android 16（API 36）以降です。写真の読み込みには Android のフォトピッカーと SAF を使用します。
