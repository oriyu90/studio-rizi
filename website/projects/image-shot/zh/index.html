Image Shot / Prism Photo修图，

Image Shot 是一款面向 Android 16 及更高版本的非破坏性、离线优先照片编辑应用。曝光、白平衡、曲线、HSL、自由角度旋转、细节与局部蒙版都以「调整指令」的形式保存，原图不会被覆盖，随时都能退回任意一步。开发期间的名称是 Prism Photo。

What it does

所有调整，都是指令。

Image Shot 保存的不是加工后的图像，而是产生这个结果的操作步骤。所以任何时候都能退回上一步，也能凭原图和记录重新做出同样的效果。

01非破坏

原片保持原样。

编辑以指令的形式记录，不会写进像素。历史只追加不覆盖，并保留每一步的状态，因此退多少步都不会损失画质。应用被系统结束后重新打开，可以从上次的位置继续。

02影调

亮度与色彩，用数值推到位。

曝光、对比度、高光、阴影、白色色阶、黑色色阶、自然饱和度、饱和度、色温、色调。滑块之外也能直接输入数值，同一套参数可以复用到另一张照片。

03曲线与 HSL

曲线，加上八种色相的 HSL。

用 master 与 R / G / B 曲线塑造层次，再按八种色相分别调整色相、饱和度与明度——只动天空的蓝，或只动皮肤的红，其余颜色不受影响。

04几何

校正水平，不必裁掉太多。

±45° 自由角度旋转（可输入数值）、水平与垂直翻转、自由裁剪。旋转与裁剪分开处理，构图可以保留，只把地平线摆正。

05细节与局部

整体看细节，局部用蒙版。

锐化与亮度降噪处理整张画面；直线、圆形与画笔蒙版带 feather，只在蒙版内部改变曝光或饱和度。适可而止，别调过头。

06导出

导出 JPEG 或 PNG。

选择质量与保存位置，导出在后台进行。EXIF 保留拍摄时间与相机信息，位置信息会被移除。

Six panels

六个面板，一张预览。

只看需要的面板，预览始终留在视野里。每个面板都能看到调整的幅度和当前的数值。

基本调整TONE

曝光、对比度、高光、阴影、白色色阶、黑色色阶、自然饱和度、饱和度、色温、色调。

曲线CURVES

master 与 R / G / B 曲线。放点即调，直接改变暗部的提升与高光的收敛。

HSLHUE / SAT / LUM

按八种色相分别调整色相、饱和度与明度。

几何GEOMETRY

±45° 自由角度旋转、水平与垂直翻转、自由裁剪。

细节DETAIL

锐化与亮度降噪，两项独立控制。

局部LOCAL

直线、圆形与画笔蒙版。先用 feather 柔化边缘，再只调整蒙版内部。

Flow

先看预览，
再慢慢调。

选好照片就进入编辑画面。在预览里确认结果，在面板里调整数值；撤销、重做与历史条数始终显示在画面下方。

  1. 01 导入

    从系统照片选择器一次导入多张，也可以用 SAF 选择文件或文件夹。

  2. 02 调整

    按六个面板依次处理影调、色彩、层次、几何与局部，数值可以直接输入。

  3. 03 对比

    用 Before/After 对照调整前后，再从历史里退回任意一步。

  4. 04 导出

    选择 JPEG 或 PNG，设定质量与保存位置。原片不会被动过。

Layout

适配你手上的屏幕。

手机竖屏时面板在预览下方，横屏时移到右侧。平板在 840dp 以上切换为双栏，预览保持足够大。

  • 手机・竖屏

    面板在预览下方，单手也能操作。

  • 手机・横屏

    预览与面板左右并排，照片看得更大。

  • 平板・双栏

    840dp 以上为双栏，预览保持在画面上。

Privacy

照片，不出设备。

Image Shot 没有声明 INTERNET 权限。既没有上传功能，也没有为了分析而向外发送照片的路径，所有编辑都在本机完成。

也不申请宽泛的存储权限：读取与保存都通过 Android 的照片选择器与 SAF（Storage Access Framework）。原片不会被覆盖，导出的 JPEG / PNG 不含位置信息。

Get started

v0.1.0，从 GitHub 获取。

Image Shot 的源码在 GitHub 公开，v0.1.0 以签名 APK 的形式在 GitHub Releases 发布。

打开 GitHub Releases
  1. 打开仓库 github.com/oriyu90/image-shot。
  2. 在 Releases 下载签名 APK，并安装到设备。
  3. 想从源码运行，克隆仓库后用 Android Studio 打开。
  4. 准备 Android SDK 36 与 JDK，执行 ./gradlew :app:assembleDebug。

系统要求为 Android 16（API 36）及以上。读取照片使用 Android 的照片选择器与 SAF。
