Image Shot / Prism PhotoEdit the photo.
Never the file.

Image Shot is a non-destructive, offline-first photo editor for Android 16 and later. Exposure, white balance, tone curves, HSL, free-angle rotation, detail and local masks are all kept as instructions — the original file is never rewritten, so every change can be undone. Working name: Prism Photo.

What it does

Adjustments are instructions.

What Image Shot stores is not a baked image but the steps that produced it. That means you can step back at any point, and rebuild the same look later — from the original or from an export.

01NON-DESTRUCTIVE

The original stays exactly as shot.

Edits are recorded as instructions, not burned into the pixels. History is append-only and keeps the state at each step, so going back never costs quality. If the app is killed, reopen it and carry on.

02TONE

Push brightness and colour by the numbers.

Exposure, contrast, highlights, shadows, whites, blacks, vibrance, saturation, temperature and tint. Every slider also accepts a typed value, so one look can be reproduced on another frame.

03CURVES & HSL

Curves, plus HSL across eight hues.

Shape tonality with master and R / G / B curves, then set hue, saturation and luminance for each of eight hue ranges — the sky's blue alone, or the reds in skin alone, without touching the rest.

04GEOMETRY

Straighten, without cropping it all away.

Free-angle rotation up to ±45° with numeric entry, horizontal and vertical flips, and free crop. Rotation and cropping are separate, so the framing stays while the horizon gets fixed.

05DETAIL & LOCAL

Global detail, local masks.

Sharpen and luminance noise reduction for the whole frame; linear, radial and brush masks with feather to move exposure or saturation only inside them. Stop before it starts to look overdone.

06EXPORT

Write out JPEG or PNG.

Choose the quality and the destination, and the export runs in the background. EXIF carries capture time and camera data across; location is stripped.

Six panels

Six panels, one preview.

Open only the panel you need while the preview stays in view. Every panel shows both how far you moved it and the number you moved it to.

ToneBASIC

Exposure, contrast, highlights, shadows, whites, blacks, vibrance, saturation, temperature and tint.

CurvesMASTER / RGB

Master and R / G / B tone curves. Place a point and move the lift and the roll-off directly.

HSLHUE / SAT / LUM

Hue, saturation and luminance for each of eight hue ranges.

GeometryROTATE / CROP

Free-angle rotation up to ±45°, horizontal and vertical flips, and free crop.

DetailSHARPEN / NR

Sharpening and luminance noise reduction, handled as separate controls.

LocalMASKS

Linear, radial and brush masks. Feather the edge, then adjust only what is inside.

Flow

Preview first, then refine.

Pick a photo and the editor opens. Check the result in the preview, move the values in the panels — undo, redo and the history count stay at the bottom of the screen.

  1. 01 Import

    Bring in several photos from the photo picker, or choose a file or folder through SAF.

  2. 02 Adjust

    Work through the six panels in order — tone, colour, tonality, geometry, local — with values you can also type.

  3. 03 Compare

    Check before and after, then step back through the history as far as you need.

  4. 04 Export

    Pick JPEG or PNG, set the quality and the destination. The original is left alone.

Layout

Sized for the screen you hold.

On a phone held upright the panels sit under the preview; in landscape they move beside it. From 840dp up, tablets switch to two panes and keep the photo large while you adjust.

Privacy

Your photos never leave the device.

Image Shot does not declare the INTERNET permission. There is no upload feature and no path that sends a photo out for analysis — every edit happens on the device.

It does not ask for broad storage access either: reading and saving go through Android's photo picker and SAF (Storage Access Framework). Originals are never rewritten, and an exported JPEG or PNG carries no location data.

Get started

Version 0.1.0, from GitHub.

The source for Image Shot is public on GitHub. Version 0.1.0 is distributed as a signed APK on GitHub Releases.

Open GitHub Releases
  1. Open the repository at github.com/oriyu90/image-shot.
  2. Get the signed APK from Releases and install it on the device.
  3. To run from source, clone the repository and open it in Android Studio.
  4. Use Android SDK 36 and a JDK, then run ./gradlew :app:assembleDebug.

Requires Android 16 (API 36) or later. Photos are read through the Android photo picker and SAF.
