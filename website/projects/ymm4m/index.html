YukkuriMovieMaker4を、Macで開くための互換環境。

YMM4Mは、公式YukkuriMovieMaker4（YMM4）をApple Silicon Mac上で動かすための非公式互換環境です。YMM4本体は同梱せず、あなたが用意した公式ZIPを検証してMac内に展開します。Wine/DXMTは同意後に固定URLから取得し、あなたのMacでビルドします。

v1.0.2をダウンロード GitHubでソースを見る

オープンソース（MIT） · 開発者: 折田悠希（Yuki_Orita） · 非公式・YMM4開発元とは無関係

特長

Macに何も持ち込まず、あなたのMacで組み立てる。

配布物はYMM4M独自のコードとスクリプトだけ。YMM4・Wine・DXMT・フォント・CrossOverは一切同梱しません。

⧉

EXTERNAL_ONLY配布

DMGにはYMM4Mのコード、bootstrap/patch/fixture、互換カタログのみ。第三者バイナリはゼロです。

⭳

固定URL＋ハッシュ検証

Wine/DXMT/フォント/LLVMは固定URL（ミラー対応）からSHA-256検証して取得。改ざんは配置前に停止します。

▦

振る舞い検証ゲート

ビルドしたランタイムは8本の互換fixture＋compute100の通過を記録してから初めて起動に使われます。

あ

日本語フォント同梱なし

Noto Sans CJK JPはWine prefix内だけに配置。UIは日本語／英語に完全対応。

⤿

版管理と切り戻し

runtime・prefix・YMM4は旧版を保持し、検証後だけcurrentを原子的に切替。ワンクリックで前の版へ。

◎

GPUの期待値を明記

UIはソフトウェア描画。プレビューとエンコードの一部だけが開発用DXMT経由でMetalを使います。

使い方

同意して、ZIPとフォルダを選ぶだけ。

  1. 公式YMM4のZIPを保存

    通常版またはLiteのZIPを、自動削除されない場所（ダウンロードフォルダなど）に保存します。

  2. 互換環境を一括インストール

    同意項目を確認して「互換環境を一括インストール」を押します。Wine/DXMTの取得・検証・ビルドは自動です。

  3. ZIPとメディアフォルダを選ぶ

    保存したYMM4 ZIPと、素材・.ymmpを置くフォルダを順に選びます。以降の準備と検証は自動です。

  4. YMM4をMacで開く

    「設定を確認」で「設定OK」を確認し、「YMM4をMacで開く」を押します。

動作環境

  • Apple Silicon Mac / macOS 26 以降
  • Rosetta 2、Xcode command line tools
  • Homebrew: brew bundle --file=Brewfile（meson / ninja / cmake / mingw-w64 / bison / harfbuzz）
  • 空き容量 約10 GB 以上（LLVM toolchain展開分を含む）
  • 公式YukkuriMovieMaker4のZIP（ユーザーが用意）

この版はApple Developer IDを持たないため、ad-hoc署名・未公証です。初回起動はmacOSの「このまま開く」を使ってください（Gatekeeper全体無効化は不要）。Windows参照比較やTier Aの編集・再生の網羅は未完了です。重要なプロジェクトは分離したコピーで試してください。
