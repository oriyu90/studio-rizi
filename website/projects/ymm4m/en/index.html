A compatibility environment for opening YukkuriMovieMaker4 on a Mac.

YMM4M runs the official YukkuriMovieMaker4 (YMM4) on Apple Silicon Macs. YMM4 itself is never bundled: YMM4M verifies the official ZIP you supply and extracts it inside your environment. Wine/DXMT are fetched from fixed URLs, with your consent, and built on your Mac.

Features

Nothing third-party in the download — it is assembled on your Mac.

The download is only YMM4M's own code and scripts. YMM4, Wine, DXMT, fonts, and CrossOver are never bundled.

⧉

EXTERNAL_ONLY distribution

The DMG holds only YMM4M's code, its bootstrap/patch/fixture files, and the compatibility catalogue. Zero third-party binaries.

⭳

Fixed URLs + hash checks

Wine/DXMT/fonts/LLVM are fetched from fixed URLs (with mirrors) and SHA-256 verified. A mismatch stops before anything is placed.

▦

Behaviour-verified gate

A built runtime is only trusted after a recorded pass of eight compatibility fixtures plus a 100-iteration compute run against those exact binaries.

あ

No bundled Japanese font

Noto Sans CJK JP lives only inside the Wine prefix. The setup UI is fully bilingual (Japanese / English).

⤿

Versioned, reversible

Runtime, prefix and YMM4 keep older versions and switch `current` atomically only after verification. One click rolls back.

◎

Honest about the GPU

The UI is drawn in software; only the preview and parts of encoding use Metal, through a development DXMT build.

How it works

Consent, then pick a ZIP and a folder.

  1. Save the official YMM4 ZIP

    Save the Standard or Lite ZIP somewhere that is not auto-deleted, such as your Downloads folder.

  2. Install the compatibility environment

    Review the consent item and press “Install the compatibility environment”. Fetching, verifying and building Wine/DXMT is automatic.

  3. Pick the ZIP and a media folder

    Choose the YMM4 ZIP you saved and a folder for assets and .ymmp files. Everything after that is prepared and verified automatically.

  4. Open YMM4 on the Mac

    Confirm “Settings OK” in “Check settings”, then press “Open YMM4 on the Mac”.

Requirements

  • Apple Silicon Mac / macOS 26 or later
  • Rosetta 2, Xcode command line tools
  • Homebrew: brew bundle --file=Brewfile (meson / ninja / cmake / mingw-w64 / bison / harfbuzz)
  • About 10 GB of free space (including the extracted LLVM toolchain)
  • The official YukkuriMovieMaker4 ZIP (you supply it)

This build has no Apple Developer ID, so it is ad-hoc signed and not notarized. Use macOS “Open Anyway” on first launch (no need to disable Gatekeeper). Windows-reference comparison and the full Tier A editing/playback matrix are not complete. Work on an isolated copy of any project you care about.
