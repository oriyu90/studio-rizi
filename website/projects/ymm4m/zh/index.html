v1.0.1 · MIT · macOS 26+ · Apple Silicon

在 Mac 上打开 YukkuriMovieMaker4 的兼容环境。

YMM4M 让官方 YukkuriMovieMaker4（YMM4）运行在 Apple Silicon Mac 上。绝不打包 YMM4 本体：YMM4M 会校验你提供的官方 ZIP 并在你的环境内解压。Wine/DXMT 在你同意后从固定 URL 获取，并在你的 Mac 上构建。

下载 v1.0.1 在 GitHub 查看源码

开源（MIT） · 开发者：折田悠希（Yuki_Orita） · 非官方，与 YMM4 开发方无关

特性

下载包不含任何第三方内容，全部在你的 Mac 上组装。

下载包只有 YMM4M 自己的代码与脚本。YMM4、Wine、DXMT、字体、CrossOver 一律不打包。

⧉

EXTERNAL_ONLY 分发

DMG 仅含 YMM4M 的代码、bootstrap/patch/fixture 与兼容目录。零第三方二进制。

⭳

固定 URL + 哈希校验

Wine/DXMT/字体/LLVM 从固定 URL（含镜像）获取并做 SHA-256 校验。不匹配则在放置前停止。

▦

行为验证门槛

构建出的运行时，必须先记录 8 个兼容 fixture 加 100 次 compute 针对这些二进制的通过结果，才会用于启动。

あ

不打包日文字体

Noto Sans CJK JP 只放在 Wine prefix 内。设置界面完整支持日文／英文。

⤿

版本化、可回退

runtime、prefix、YMM4 保留旧版本，验证后才原子切换 current。一键回到上一版本。

◎

如实说明 GPU

界面为软件渲染；只有预览与部分编码通过开发版 DXMT 使用 Metal。

使用方法

同意后，选一个 ZIP 和一个文件夹。

  1. 保存官方 YMM4 ZIP

    把通常版或 Lite 的 ZIP 保存到不会被自动删除的位置（如下载文件夹）。

  2. 一键安装兼容环境

    确认同意项，点击“一键安装兼容环境”。获取、校验、构建 Wine/DXMT 全自动。

  3. 选择 ZIP 与媒体文件夹

    依次选择保存的 YMM4 ZIP，以及存放素材与 .ymmp 的文件夹。之后的准备与校验全自动。

  4. 在 Mac 上打开 YMM4

    在“检查设置”中确认“设置 OK”，然后点击“在 Mac 上打开 YMM4”。

运行环境

  • Apple Silicon Mac / macOS 26 及以上
  • Rosetta 2、Xcode command line tools
  • Homebrew：brew bundle --file=Brewfile（meson / ninja / cmake / mingw-w64 / bison / harfbuzz）
  • 约 10 GB 以上可用空间（含解压后的 LLVM 工具链）
  • 官方 YukkuriMovieMaker4 的 ZIP（由你提供）

此版本没有 Apple Developer ID，因此为 ad-hoc 签名且未公证。首次启动请使用 macOS 的“仍要打开”（无需关闭 Gatekeeper）。Windows 参考对比与完整的 Tier A 编辑／播放矩阵尚未完成。重要项目请用独立副本测试。
