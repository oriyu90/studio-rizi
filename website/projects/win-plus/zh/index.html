Windows 10 / 11 · tray resident utility

住在托盘里，
为 Windows 加把手。

win-plus 把触控板映射、输入设备识别、自定义快捷键、截图与速记装进一个轻量 Windows 常驻应用。

FIVE JOBS, ONE TRAY ICON

常用操作，交给指尖与按键。

全部可用图形界面配置。启动后常驻托盘，待机 CPU 0%、约 50MB。

01

触控板映射

三指轻触打开任务视图，三指滑动切换虚拟桌面等。附带手指数量测量。

↘
02

输入设备识别

按真实名称与总线（USB/蓝牙/内置）列出已连接设备，可建设备专属按键规则。

↘
03

自定义快捷键

32 种预设（媒体键、音量、Win+D 等）加自由输入。点一下输入框再按键即可注册。

↘
04

截图

多配置、全屏/窗口/区域截取、按配置分文件夹，预览可直接拖放给其他应用。

↘
05

速记

一键呼出的小弹窗。6 秒自动关闭，重启后内容仍在。粘贴强制纯文本，只收图片。

↘
