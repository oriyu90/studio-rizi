GlintVNC

面向 Intel Mac 的安全设计 Rust VNC 查看器

macOS 13+Rustv1.0.0日英 UI

GlintVNC（グリントVNC）是为 2017 Intel MacBook Pro / macOS Ventura 13.7.8 开发的 Rust 原生 VNC 查看器。支持 RFB 3.3 / 3.7 / 3.8 与 VNCAuth，并可安全解码 Raw、CopyRect 和 ZRLE 编码。

以安全为先的设计

来自远程服务器的每个字节都视为不可信输入。解码器检查尺寸、矩形与解压后大小，将每次更新的 RGBA 累积量限制为 128 MiB、帧缓冲限制为 16 Mpx，并设置 15 秒读取超时，避免停摆的服务器长期占用线程与内存。

  • 核心启用 #![forbid(unsafe_code)]，全部为 safe Rust
  • 带边界检查的 Raw / CopyRect / ZRLE 解码
  • 每次更新的内存预算与网络读取超时
  • 断开连接或失去焦点时释放按键与鼠标状态
  • 密码仅存于 Keychain，不写入 JSON、日志或命令行参数
  • 仅通过显式配置才允许未加密连接

兼容性与现有功能

已实现 RFB 3.3 / 3.7 / 3.8 握手、VNCAuth、Raw / CopyRect / ZRLE 编码，以及 Cursor、DesktopSize、LED State 伪编码，并考虑 x11vnc（LibVNCServer）与 TigerVNC 的行为。差分矩形串流和局部 GPU 上传让拖动更新保持轻量。

  • 差分矩形串流 + TextureHandle::set_partial
  • 16 ms 最新值优先的指针移动节流
  • DesktopSize 之后按规范发送非增量请求
  • 支持 x11vnc 的 LED State（0xFFFE0000）
  • 浮动栏「重绘」/ Cmd+R 可立即清除残影
  • 尚未实现：TLS/VeNCrypt、Tight/Hextile、Continuous Updates

完整的日语 / 英语界面

应用界面完整支持日语和英语。连接列表、配置文件编辑、设置和会话控制栏在两种语言下功能一致。显示缩放（Fit / 1:1 / Stretch）与键位映射按连接分别设置。

下载

可从 GitHub Releases 下载 DMG。该文件为 ad-hoc 签名，未经过 Apple 公证。首次启动需右键 → 打开，或在「系统设置 → 隐私与安全性」中允许。每次重新构建签名都会变化，Keychain 可能再次请求授权。
