GlintVNC

Intel Mac 向け・安全設計の Rust 製 VNC ビューア

macOS 13+Rustv0.1.0日英 UI

GlintVNC（グリントVNC）は、2017 Intel MacBook Pro / macOS Ventura 13.7.8 を対象に開発した Rust 製のネイティブ VNC ビューアです。RFB 3.3 / 3.7 / 3.8 と VNCAuth に対応し、Raw・CopyRect・ZRLE の各エンコーディングを安全にデコードします。

安全を優先した設計

リモートから届くデータはすべて信頼できない入力として扱います。デコーダは寸法・矩形・展開サイズを厳しく検査し、1 更新あたりの RGBA 蓄積を 128 MiB、フレームバッファを 16 Mpx に制限しています。ネットワーク読み取りには 15 秒のタイムアウトを設け、停止したサーバーがワーカーやメモリを占有しません。

  • #![forbid(unsafe_code)]] をコアに適用、すべて safe Rust
  • 境界チェック付きの Raw / CopyRect / ZRLE デコーダ
  • 更新ごとのメモリ予算と読み取りタイムアウト
  • 切断・フォーカス喪失時にキーとボタンを確実に解放
  • パスワードは Keychain のみ、JSON・ログ・引数には保存しない
  • 暗号化なし接続は明示的なプロファイル設定でのみ許可

互換性と既存機能

RFB 3.3 / 3.7 / 3.8 のハンドシェイク、VNCAuth、Raw / CopyRect / ZRLE を実装済みです。Cursor、DesktopSize、LED State の擬似エンコーディングにも対応し、x11vnc（LibVNCServer）と TigerVNC の双方を意識した動作をします。差分矩形ストリーミングと部分 GPU 転送で、ドラッグ中の更新を小さく抑えます。

  • Dirty-rect ストリーミング + TextureHandle::set_partial
  • 16 ms のポインタ移動スロットル（最新値優先）
  • DesktopSize 後の仕様どおりの非増分再描画
  • x11vnc の LED State（0xFFFE0000）にも対応
  • 浮動バーの「再描画」/⌘R で残像を即消去
  • 未実装: TLS/VeNCrypt、Tight/Hextile、Continuous Updates

日本語 / 英語の完全な UI

アプリ本体の UI は日本語と英語に完全対応しています。接続一覧、プロファイル編集、設定、セッション操作バーまで、両言語で同じ機能を利用できます。表示スケール（Fit / 1:1 / Stretch）とキーマップは接続ごとに設定できます。

ダウンロード

GitHub Releases から DMG をダウンロードできます。ad-hoc 署名であり、Apple 公証は行っていません。初回起動は右クリック→「開く」、または「システム設定 → プライバシーとセキュリティ」での許可が必要です。再ビルドごとに署名が変わるため、Keychain の許可を再度求められる場合があります。
