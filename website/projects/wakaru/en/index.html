From source to insight, without breaking the flow.

Importing, reading, searching, and working with AI stay in the same project. The original material and its citations remain at the centre.

  1. 01

    Import without format anxiety

    Bring in PDFs, Office files, spreadsheets, text, images, web pages, audio, and video. Originals remain untouched and organised by project.

  2. 02

    Read and search in one place

    Position-aware tabs, in-view search, and hybrid keyword plus semantic search reduce the friction of moving between sources.

  3. 03

    Work with the citations in view

    Read explanations in Live Illustrator and create outputs in Studio. Follow an answer back to its source whenever you need to verify it.

Document-centred guidance, even for smaller models.

Source text stays separate from AI instructions, while a short verify-and-write workflow keeps explanations and files grounded.

Page-aware PDF reading VIEWER
PDF and slide text is shown page by page, preserving position for search and explanation.
Search that degrades safely SEARCH
Use semantic search with a configured embedding API, while keyword search remains available without one.
AI with a workspace STUDIO
Document requests create complete files in the project workspace. Sources, tabs, files, and tool output are treated as data, never commands.
A reading environment you can tune ACCESS
Light, dark, and monochrome themes; 80–150% scaling; inversion, exposure reduction, and sharpening.
Two AI API formats AI
Choose OpenAI-compatible or Anthropic-compatible per connection for local servers or cloud APIs.

Your documents stay on your Mac.

No telemetry and no automatic document uploads. Network access happens only when you initiate an import, model download, or configured service connection.

  • API keys are stored in the operating system credential store, not the app database or settings.
  • Document text, prompts, and API keys are not written to application logs.
  • Original files are never modified or deleted.
  • Import, viewing, keyword search, and TXT export work without an AI connection.

Start with a document already on your Mac.
