資料を、根拠つきで「わかる」に。

PDF、音声、動画、表計算。ひとつの場所で読み、探し、AIに解説させ、すべての引用から元資料へ戻れます。資料は作業中もMacに残ります。

macOS版を入手 ↓使い方を見る

Apple Silicon · macOS 12+ · MIT License · v0.0.3 release

資料から理解まで、流れを切らない。

取り込み、閲覧、検索、AIとの作業を同じプロジェクトで進め、元資料と引用を常に中心へ置きます。

  1. 01

    形式を気にせず取り込む

    PDF、Office文書、表、テキスト、画像、Web、音声、動画に対応。原本は変更せずプロジェクト単位で整理します。

  2. 02

    同じ場所で読み、探す

    位置を保持するタブ、表示内検索、日本語キーワード検索、埋め込みAPI設定時の意味検索を利用できます。

  3. 03

    引用を見ながら成果を作る

    Live Illustratorで平易な解説を読み、Studioで文書をファイルとして作成。必要なときは回答から原資料へ戻れます。

低性能モデルでも迷いにくい、資料中心の設計。

資料本文をAIの命令から分離し、根拠確認と文書保存を短い固定手順で支えます。

ページ単位のPDF読解 VIEWER
PDFとスライドの抽出テキストをページ単位で表示し、位置を保ったまま検索・解説へ渡します。
検索の安全な縮退 SEARCH
埋め込み対応APIがあれば意味検索を併用し、未設定やオフライン時はキーワード検索を維持します。
2種類のAI API AI
接続ごとにOpenAI互換またはAnthropic互換を選び、ローカルサーバーとクラウドAPIを管理できます。
成果物を保存するStudio STUDIO
文書作成依頼はワークスペース内のファイルとして保存。資料、他タブ、ツール結果を命令として実行しません。
情報欠落を止める整理機能 ORGANIZER
整理結果が原文の70%未満ならMarkdown保存を止め、差分確認または原文TXT保存を案内します。
読みやすい表示 ACCESS
ライト、ダーク、モノトーン、80〜150%表示に対応。ダークテーマの主要文字は白で表示します。

資料はMacに残ります。

テレメトリも自動送信もありません。通信は利用者が開始した取り込み、モデルダウンロード、設定済みサービス接続時だけです。

  • APIキーはOSの資格情報ストアに保存し、アプリDBや設定へ平文保存しません。
  • 資料本文、プロンプト、APIキーをアプリログへ記録しません。
  • 原本ファイルを変更・削除しません。
  • AI未設定でも取り込み、閲覧、キーワード検索、TXT保存を利用できます。

Macにある資料から始める。

GitHub Releasesで配布しています。Developer ID署名とApple公証は未実施のため、初回はFinderでアプリを右クリックし「開く」を選ぶ場合があります。
