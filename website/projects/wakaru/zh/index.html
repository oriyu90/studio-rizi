将资料变成有依据的“理解”。

PDF、音频、视频、电子表格。在同一处阅读和检索，让 AI 进行解读，再沿每条引用回到原始资料。WAKARU 让资料留在你的 Mac 上，同时推进理解。

获取 macOS 版 ↓查看工作方式

Apple Silicon · macOS 12+ · MIT License · v0.0.0 pre-release

从资料到理解，不打断思路。

导入、阅读、检索与 AI 协作都在同一个项目中完成。原始资料与引用始终位于工作的中心。

  1. 01

    无需担心格式，直接导入

    支持 PDF、Office 文档、表格、文本、图片、网页、音频与视频。原文件保持不变，并按项目整理。

  2. 02

    在同一处阅读与查找

    保留阅读位置的标签页、页内查找，以及关键词与语义混合检索，减少在资料间往返的负担。

  3. 03

    在引用可见的情况下工作

    在 Live Illustrator 中阅读解读，在 Studio 中制作成果。需要核验时，可随时从回答返回原资料。

即使使用较小模型，也以资料为中心。

资料正文与 AI 指令相互分离，并通过简短的核对与写入流程保持解读和文件有依据。

按页阅读 PDF VIEWER
按页显示 PDF 与幻灯片的抽取文本，并保留位置用于搜索和讲解。
安全降级的检索 SEARCH
配置嵌入 API 时使用语义检索；未配置或离线时仍保留关键词检索。
带工作区的 AI STUDIO
文档请求会在工作区生成完整文件。资料、标签页、文件和工具输出只被视为数据。
可调节的阅读环境 ACCESS
支持浅色、深色、单色主题与 80–150% 缩放；深色主题主要文字为白色。
两种 AI API 格式 AI
每个连接可选择 OpenAI 兼容或 Anthropic 兼容格式，适用于本地服务与云端 API。

资料留在你的 Mac 上。

没有遥测，也不会自动上传资料。只有当你主动导入、下载模型或连接已配置服务时才会联网。

  • API 密钥保存在操作系统凭据存储中，不写入应用数据库或设置文件。
  • 资料正文、提示词与 API 密钥不会写入应用日志。
  • 不会修改或删除原始文件。
  • 即使未配置 AI，也可使用导入、查看、关键词检索与 TXT 导出。

从 Mac 上已有的一份资料开始。
